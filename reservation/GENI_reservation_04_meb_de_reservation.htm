( M.E.B. : Mise En Barre )

L'opération de mise en barre consiste à optimiser l'utilisation des barres à commander selon les pièces à fabriquer.

Calculer une mise en barre

  1. Saisir le N° Resa et valider par Entrée
  2. Cliquer sur ou pour lancer la mise en barre de l'article courant ou des tous les articles.
  3. GENI lance automatiquement l'application de calcul des mises en barre développée sous Microsoft Access
    • Sous Access
      1. Cliquer sur Import GENI
      2. Se positionner sur la session active
      3. Cliquer sur calculer tout
      4. Access affiche les besoins non satisfaits par session > Vérifier et résoudre les causes des besoins non satisfaits (généralement la borne de longueur de barre mini ). Lancer un recalcul pour la session
      5. Cliquer sur Fermer
      6. Si aucun message d'erreur n'apparaît, cliquer sur Export GENI
    • Retour sous GENI
  4. Les résultats ainsi que les paramètres du calcul effectué sous Access sont repris par GENi et affichés à l'écran.
  5. Cliquer sur pour enregistrer la mise en barre
  6. Cliquer sur pour l'éditer.
