Composant logiciel enfichable MMC FrontPage

Le composant logiciel enfichable MMC FrontPage remplace l'utilitaire Fpsrvwin : découvrez les différences

Si vous avez utilisé des versions antérieures des extensions serveur FrontPage, vous avez peut-être fait appel à l'utilitaire Fpsrvwin pour les administrer. Fpsrvwin était un utilitaire permettant d'effectuer des tâches administratives telles que l'installation, le contrôle, la correction et la suppression des extensions serveur sur un serveur Web.

Le composant logiciel enfichable MMC FrontPage fournit les fonctions les plus courantes de Fpsrvwin et permet, en outre, les opérations suivantes :

  • Définir les propriétés du site, comme les performances, les options de messagerie, les autorisations de script et la journalisation des opérations d'auteur.
  • Créer des sous-sites Web.
  • Ajouter un administrateur.
  • Convertir les dossiers en sous-sites Web, et vice-versa.
  • Supprimer les sous-sites.
  • Ouvrir un site Web dans FrontPage (si FrontPage est installé sur le même ordinateur que le site Web).
  • Spécifier un langage de script par défaut.
  • Journaliser les opérations d'auteur.
  • Recalculer les liens hypertexte.
