Rappel pour les utilisateurs occasionnels la consultation des stocks se fait sur : Site = SP-PINON - Magasin = MG-PINON-00
Dans les zones de couleur bleu ou grisé, vous pouvez faire apparaître une liste de choix en appuyant sur F4.
Dans toutes les listes, il est possible de créer un filtre (une requête) avec les raccourcis F2 Shift+F2

Saisie d'une nouvelle commande:

  1. Saisir les informations d'entête, CDE, Site, Responsable, etc;
  2. Ligne article, Entrée (le numéro de ligne s'affiche automatiquement)
  3. Saisir le code article générique, appuyer sur F4 pour rechercher l'article éphémère à commander.
  4. Si l'article est inexistant, Ctrl + 5 ou cliquer sur pour créer un nouvel article éphémère.
  5. Valider par Entrée les champs Réf. Fournisseur, PU HT, Montant.
    Ces différentes valeurs sont reprises automatiquement, de l'entête de commande pour le code fournisseur, de la fiche article ou du tarif pour le PU HT.
  6. L'unité de quantité par défaut s'affiche, la modifier si besoin
  7. Saisir le code chantier ou faire une recherche avec F4
  8. En fin de ligne, le champ destination permet de préciser un lieu de destination sur un chantier ex: Tour A, Tour B
  9. Se positionner sur le détail des livraisons en appuyant sur F8
  10. Saisir la date de livraison et la quantité à livrer (multiple de U. Qte défini dans la ligne article)
  11. Valider la quantité en appuyant sur F5
  12. Redescendre sur la ligne article en appuyant sur F9
  13. Créer une nouvelle ligne (F7), saisir les informations requises
    Il est possible de recopier la ligne précédente avec (F12), ou seulement un champ avec ( Shift + F7 ).
  14. En fin de saisie, appuyer sur Ctrl + 4 ou cliquer sur pour re-calcul du tarif.
  15. Imprimer la commande en cliquant sur ou pour une édition avec ou sans le détail du tarif.

Note : Si un prix unitaire est erroné ou fait l'objet de conditions particulières non prises en compte dans le tarif, il est possible de modifier ce prix en cliquant sur . 

Exemple : Dans la cas d'une commande de vis, la quantité unitaire par défaut est UN,
Hors, à la commande, on achète des boites de 1000, 
Il faut donc modifier l'unité de quantité par MILLE, et dans la ligne de livraison 
saisir le nombre de boite à livrer et non le nombre de vis.

Consulter une commande existante:

  1. Dans CDE, saisir un numéro de commande ou faire une recherche par liste de choix (F4)
  2. Valider par Entrée

Supprimer une commande non livrée

  1. Se positionner sur Qté, appuyer sur Shift + F12, valider par F5
  2. Se positionner sur Ligne, appuyer sur Shift + F12, valider par F5
  3. Se positionner sur CDE, appuyer sur Shift + F12
