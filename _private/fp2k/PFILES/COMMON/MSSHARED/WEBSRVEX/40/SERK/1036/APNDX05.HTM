Kit de ressources des extensions serveur Microsoft FrontPage 2000

Annexes

Répertoires FrontPage spéciaux et emplacements de stockage

Cette annexe répertorie les dossiers et fichiers ajoutés par FrontPage à chaque site Web racine ou sous-site Web.

 

Dossier Fichiers Fonction
_overlay *.gif Fichiers de superposition de texte sur les boutons de navigation et GIF. Ces fichiers sont des GIF transparents qui recouvrent des images de bannière ou de bouton afin de créer un texte entier sur une image composite de bouton de navigation ou GIF.
_derived *.htx, *.gif Fichiers générés de façon dynamique par FrontPage et pouvant être générés à nouveau à tout moment, tels que les fichiers *.htx, créés par le composant de recherche et le texte composite sur les images GIF.
_borders Top.htm, Left.htm, Right.htm, Bottom.htm Fichiers de définition de bordures partagées inclus dans les pages qui utilisent des bordures partagées.
_fpclass *.class Fichiers de classe Java compilés qui implémentent certaines caractéristiques FrontPage.
_themes Fichiers *.gif, *.inf, *.css, *.utf8, *.jpg pour chaque thème Stockage de thèmes. Chaque thème qui est appliqué à un site Web est téléchargé vers un sous-répertoire à nom unique du répertoire _themes.
_private   Ce dossier est créé dans chaque site Web FrontPage étendu. Il contient des fichiers utilisateur qui ne sont pas accessibles à un visiteur du site.
_vti_bin Shtml.dll, Shtml.exe

Fichiers exécutables des extensions serveur FrontPage pour les fonctions d'exécution. Ces fichiers n'existent pas sur certains serveurs.
  Fpcount.exe Section d'exécution du composant Compteur d'accès.
_vti_bin/_vti_aut Author.dll, Author.exe Fichiers exécutables des extensions serveur FrontPage pour les fonctions d'opérations d'auteur. Ces fichiers n'existent pas sur certains serveurs.
_vti_bin/_vti_adm Admin.dll, Admin.exe Fichiers exécutables des extensions serveur FrontPage pour les fonctions de sécurité. Ces fichiers n'existent pas sur certains serveurs.
_vti_bot   Utilisé pour les composants FrontPage personnalisés (WebBots) qui ont été créés à l'aide de FrontPage SDK. Ce dossier comprend les implémentations des composants personnalisés. Les composants personnalisés installés dans ces répertoires sont téléchargés de façon facultative vers l'ordinateur de l'auteur lorsque ce dernier les insère.
_vti_cnf Pour chaque page HTML et graphique d'un site Web FrontPage étendu, il existe un fichier de configuration du même nom. Chaque page de configuration comprend un ensemble de paires nom/valeur qui permettent d'identifier, par exemple, l'auteur de la dernière modification d'une page ou l'éditeur associé à un fichier.
_vti_pvt _x_todo.htm Comprend les paramètres en cours de la liste des tâches.
  _x_todoh.htm Comprend les modifications apportées à la liste des tâches.
  Access.cnf Comprend les informations de contrôle d'accès relatives au serveur HTTP.
  Administrators.pwd Noms et mots de passe codés des administrateurs. Uniquement sur les serveurs Netscape.
  Authors.pwd Noms et mots de passe codés des auteurs. Uniquement sur les serveurs Netscape.
  Bots.cnf Utilisé pour les composants FrontPage personnalisés (WebBots) qui ont été créés à l'aide de FrontPage SDK.
  Botinfs.cnf Liste d'informations sur les composants FrontPage personnalisés (WebBots)
  Deptodoc.btr Base de données des dépendances pour le site Web.
  Doctodep.btr Base de données des dépendances pour le site Web.
  Frontpg.lck Site Web racine uniquement. Fichier de verrouillage destiné à éviter l'accès simultané aux ressources serveur du site Web. Ce fichier doit avoir une capacité de zéro octet pendant les périodes d'inactivité. Avec les serveurs IIS et WebSite, ce fichier se trouve sous
C:\Program Files\Microsoft FrontPage\40\Temp, et non dans le répertoire _vti_pvt de la zone de contenu du site Web.
  Linkinfo.cnf Liens vers la page précédente pour les URL qui ne sont pas sur le site Web en cours.
  Service.cnf Comprend les méta-informations à propos du site Web.
  Service.grp Répertorie les membres des groupes Administrateurs et Auteurs. Uniquement utilisé sur les serveurs CERN et NCSA.
  Service.pwd Comprend les fichiers de mots de passe codés. Non utilisé sur les serveurs IIS et WebSite.
  Service.stp Comprend le chemin d'accès du système de fichier absolu des fichiers du site Web FrontPage étendu Service.pwd et Service.grp. Uniquement utilisé sur les serveurs CERN et NCSA.
  Services.cnf Comprend la liste des sous-sites Web.
  Services.org Fichier utilisé comme base de Services.cnf lors de la réinstallation des extensions serveur, de façon à ce que les sous-sites Web ne soient pas créés comme des sous-répertoires du site Web racine.
  Service.lck Fichier de verrouillage destiné à éviter l'accès simultané aux ressources du site Web. Ce fichier doit posséder une capacité de zéro octet pendant les périodes d'inactivité.
  Structure.cnf Comprend le stockage des informations de navigation du site Web FrontPage étendu.
  Svcacl.cnf Fichier utilisé pour stocker les paramètres d'autorisations uniques des sous-sites Web et les restrictions des adresses IP afin que, lors de la réinstallation des extensions serveur, les paramètres d'autorisations soient à nouveau correctement appliqués aux sous-sites.
  Users.pwd Noms et mots de passe codés des utilisateurs finals. Uniquement sur les serveurs Netscape.
  Uniqueperm.cnf La présence de ce fichier indique que le sous-site Web est doté de paramètres d'autorisations uniques, par opposition aux autorisations héritées du site Web racine. N'existe que sur les sous-sites Web. Utilisé uniquement sur IIS.
  Writeto.cnf Liens vers la page précédente pour les fichiers dans lesquels les utilisateurs du site Web peuvent écrire, tels que les fichiers de résultats du programme de traitement Enregistreur de résultats. Ces fichiers sont dotés d'un paramètre de sécurité moins strict que le contenu d'un site Web normal.
_vti_map   Comprend les fichiers d'images interactives.
_vti_script *.idq Fichiers de requêtes créés par le composant de recherche FrontPage lorsque vous utilisez le serveur d'index sur IIS.
_vti_txt   Ce dossier contient les index de texte uniquement pour le système de recherche WAIS. Il n'est pas utilisé par le serveur d'index sur IIS.
fpdb   La base de données Microsoft Access créée par FrontPage dans le programme de traitement de formulaire Enregistrer dans une base de données, est enregistrée dans ce dossier. Il en est de même pour la base de données exemple comprise dans FrontPage .
