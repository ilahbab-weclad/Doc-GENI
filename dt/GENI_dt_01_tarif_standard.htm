Note : la gestion du tarif standard est identique à la gestion du tarif achats.

Le tarif standard permet de valoriser les informations en provenance de la saisie graphique suite à création de la gamme et de la nomenclature. Il permet également de valoriser les commandes usine.

Tarif standard des articles de type vitrage

Le tarif des vitrages est calculé à partir de l'article générique RV-xxx
Le seul critère utilisé pour le tarif standard est la composition du vitrage,

Si il est nécessaire de créer un tarif plus complexe : 
ex: Si le vitrage a une surface supérieure à X pour la composition C, ajouter une plus value P.

il faut créer un tarif pour l'article éphémère.

L'écran de gestion des tarifs est constitué de différentes zones:

  1. Article, Structure, Chantier
    Utilisé pour l'interrogation de la base.
    Dans l'exemple ci-dessus, nous recherchons tous les tarifs enregistrés pour l'article TA-PRO.
  2. Liste des tarifs
    Affiche les tarifs en relation avec les informations saisies précédemment.
    Dans l'exemple ci-dessus, nous nous intéressons au premier tarif affiché, tarif défini pour le fournisseur F-00093 et pour le chantier CH-520172. Ce tarif a été saisie avec comme critère principal: le poids.
  3. Détail du tarif
    Affiche le détail du tarif sélectionné
    Dans l'exemple ci-dessus, le prix à appliquer lors de la commande correspond au poids commandé, différentes tranches sont considérées.

Créer un nouveau tarif

  1. Saisir les critères Article, Structure et Chantier et valider par Entrée
    le système affiche les éventuels tarifs déjà existants
  2. Se positionner sur une ligne de tarif.
  3. Choisir dans le menu Edition > Insérer un enregistrement (F7),
  4. une nouvelle ligne vierge apparaît,
  5. renseigner les différents champs relatifs au tarif à saisir:
    N°, Ref Tarif, Rgt, Article, Structure, Chantier, (ces trois éléments sont repris automatiquement si ils ont été renseignés précédemment), Date début, Date fin (si connue), Qté inf & Qté sup (si plusieurs bornes, utiliser les lignes de détail), unité, valeur (si plusieurs bornes, renseigner les lignes de détail), devise.
  6. Se poistionner sur le détail de tarif, insérer un nouvel enregistrement (F7)
  7. Saisir les informations relatives au tarif:
    N° de ligne, type, etc...
  8. valider les changements en appuyant sur F5.

Note - cas particulier : Nous remarquons ci-dessus deux lignes avec les mêmes bornes de poids ( 0-300 ), la première ligne ne possède pas de code de calcul car elle correspond à une plus value appliquée aux commandes inférieures à 300 kg.

Utilisation avancée : Si vous désirez faire évoluer un tarif existant, afin de ne pas recopier l'intégralité des lignes d'information, il est possible de copier un tarif existant et de ne modifier que les lignes qui diffèrent (date de début, prix, devise, ...)

Simulation - Test tarification
 

Simulation - test tarification

Cet écran permet de saisir une liste d'article pour un fournisseur et un chantier spécifiques et de lancer un calcul de tarif.

Calculer un tarif :

  1. Saisir un code fournisseur ou en rechercher un avec la liste de choix (F4)
  2. saisir un code chantier ou en rechercher un avec la liste de choix (F4) (si connu et utilisation d'un tarif spécifique au chantier.)
  3. saisir un ou plusieurs articles à commander
  4. cliquer sur pour lancer le calcul de tarif
    le programme scrute les tarifs et affiche le détail du calcul de prix.

Note : Il est possible dans certains cas, de devoir modifier un prix unitaire. Suite à la modification de la ligne, il faut dans ce cas relancer le calcul avec le bouton .

Ordre prioritaire d'application du prix d'achat

  1. Code article ( exemple : 77-242-TN15-6500 )
  2. Article générique ( exemple : 77-242 )
  3. Article de regroupement ( exemple : TA-PRO )

Note : Un prix spécifique à un chantier est prioritaire par rapport à un prix général.

Si les trois cas sont décrit, le prix de la commande sera le premier prix trouvé dans l'ordre cité.
( dans ce cas, le prix de larticle 77-242-TN15-6500 prévaut )

La recherche d'un prix se fait toujours du plus détaillé au plus général.

Une fois le type de tarif à utiliser défini, le logiciel se positionne sur la ligne de détail dont les quantités inf. et sup. correspondent à la quantité à commander.

Si un prix d'achat n'apparaît pas lors de la saisie d'une commande.

  • Vérifier la date de début du tarif :
    Si la date de début est le 20/09/2001, le tarif saisi sera prix en compte à partir du 21/09/2001.
  • Vérifier le code structure du fournisseur.

 
Requête avancée : Trouver les tarifs d'une teinte particulière

Dans cet exemple on  cherche les tarifs pour le code teinte contenant POLI

  1. lancer une requête F2 dans la liste du haut.
  2. Dans la colonne N°, saisir :A
  3. Dans l'éditeur de Query/Where saisir
    :a in (select no_tar from tar_lig where soc='4' and b_inf_c like '%POLI%')
  4. Valider par OK
