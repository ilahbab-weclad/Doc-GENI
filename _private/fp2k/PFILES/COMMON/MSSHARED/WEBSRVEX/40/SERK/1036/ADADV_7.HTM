Configuration de comptes d'utilisateur pour une utilisation dans les projets Visual SourceSafe

Microsoft Visual SourceSafe contient un utilitaire appelé Administrateur Visual SourceSafe permettant de créer et de configurer des comptes pour les utiliser au sein de projets VSS. Pour Visual SourceSafe version 5.0 ou ultérieure, l'Administrateur Visual SourceSafe est disponible dans le menu Démarrer.

Pour activer l'intégration de Visual SourceSafe avec FrontPage, ajoutez les comptes d'utilisateur suivants avec l'Administrateur Visual SourceSafe :

 

Utilisateurs/Groupes Autorisations VSS
Tous les groupes et utilisateurs de type administrateur dans FrontPage lecture-écriture
Tous les groupes et utilisateurs de type auteur dans FrontPage lecture-écriture
Sous Internet Information Services ou Peer Web Server, le compte visiteur Internet lecture
Sur tous les serveurs Web excepté Internet Information Services ou Peer Web Server, le compte sous lequel le serveur Web fonctionne lecture

 

Pour ajouter un compte d'utilisateur ou de groupe dans l'Administrateur Visual SourceSafe :

  1. Exécutez l'Administrateur Visual SourceSafe.
  2. Dans le menu Utilisateurs, choisissez Ajouter un utilisateur.
  3. Dans la boîte de dialogue Ajouter un utilisateur, tapez le nom de l'utilisateur ou du groupe dans le champ Nom d'utilisateur et laissez le champ Mot de passe vide.
  4. Cliquez sur OK.

 

Comptes Visual SourceSafe

Configuration des comptes dans Visual SourceSafe Administrator.

  1. Dans Visual SourceSafe Administrator, ajoutez les utilisateurs FrontPage (sans mots de passe).
  2. Dans le menu Outils, cliquez sur Options, cliquez sur l'onglet Généralet assurez-vous que la case Utiliser le nom du réseau pour une connexion automatique de l'utilisateur est cochée.

 

Compte anonyme

Si vous utilisez un compte anonyme, vous devez le configurer sur le serveur Web.

  1. Assurez-vous que le compte anonyme possède le même mot de passe dans IIS Service Manager et Gest. des utilisateurs pour les domaines. Vous devrez entrer à nouveau le mot de passe aux deux emplacements.

    Pour définir ou modifier le mot de passe du compte anonyme dans le IIS Service Manager, procédez comme suit :

    • Dans le Gestionnaire des services Internet, ouvrez le dossier Internet Information Server, cliquez avec le bouton droit de la souris sur le serveur Web, puis cliquez sur Propriétés dans le menu contextuel.
    • Dans Propriétés principales, cliquez sur Service WWW , puis sur Modifier.
    • Cliquez sur l'onglet Sécurité de répertoire, puis sur Connexions anonymes et contrôle d'authentification, cliquez sur Modifier.
    • Sous Autoriser les connexions anonymes, cliquez sur Modifier.
    • Modifiez le mot de passe pour le compte anonyme si nécessaire, puis fermez toutes les boîtes de dialogue restantes.

      Notez le nom du compte anonyme, car vous devrez l'identifiez dans le Gest. des utilisateurs pour les domaines.

    • Ouvrez le Panneau de configuration, puis cliquez deux fois sur Services.
    • Cliquez sur Service de publication World Wide Web, cliquez sur Arrêter, puis sur Oui pour confirmer et sur Démarrage.

    Pour définir ou modifier le mot de passe du compte anonyme dans le Gest. des utilisateurs pour les domaines, procédez comme suit :

    • Dans Gest. des utilisateurs pour les domaines, sous NomUtilisateur, cliquez sur le compte anonyme (si vous n'êtes pas certain de quel compte il s'agit, reportez-vous à la procédure précédente).
    • Dans le menu Utilisateur, cliquez sur Propriétés.
    • Modifiez le mot de passe pour le compte anonyme si nécessaire, puis cliquez sur OK.

       

      Les mots de passe n'excèdent pas 14 caractères, sans tenir compte de la longueur actuelle de votre mot de passe.

  2. Assurez-vous que le compte anonyme possède les droits pour Ouvrir une session localement :
    • Dans le Gest. des utilisateurs pour les domaines, sous NomUtilisateur, cliquez sur le compte anonyme.
    • Dans le menu Stratégies, cliquez sur Droits de l'utilisateur.
    • Dans la liste de Droite, cliquez sur Ouvrir une session localement. Assurez-vous que le compte anonyme est répertorié dans la boîte Accorder à de manière individuelle ou en tant que membre d'un des groupes, puis cliquez sur OK.
  3. Assurez-vous que le compte anonyme peut ouvrir une session localement sur le serveur Web :
    • Dans le Gest. des utilisateurs pour les domaines, sous NomUtilisateur, cliquez sur le compte anonyme.
    • Dans le menu Utilisateur, cliquez sur Propriétés.
    • Désactivez les boîtes L'utilisateur doit changer de mot de passe à la prochaine ouverture de session et Compte désactivé, puis cliquez sur OK.
  4. Dans le l'Administrateur Visual SourceSafe, ajoutez le compte anonyme comme utilisateur sans mot de passe.
  5. Configurez les autorisations pour le compte anonyme dans la structure de répertoires Visual SourceSafe (reportez-vous à la section précédente Configuration des autorisations dans le répertoire Visual SourceSafe).
