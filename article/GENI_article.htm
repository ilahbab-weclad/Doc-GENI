Attention ! : le code article est différent du code abrégé.
  Profils

Le code article "BE" et "GENI" peut être différent.

En règle générale: 

  • les articles BE qui ne commencent pas par un chiffre ont un 
    0     (zéro) ajouté au début du code article GENI
    (exemple : 0MR14)

  • les profilés avec une coupure thermique (barrette) reçoivent un 
    B     en fin de code article.
    (exemple : 35-57B)

  • les articles provenant d'un catalogue fournisseur reçoivent 
    0F     (zéro F) au début du code article
    (exemple : 0FP0555)
