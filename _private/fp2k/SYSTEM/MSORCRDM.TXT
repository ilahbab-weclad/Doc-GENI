------------
PRÉSENTATION
------------

Le pilote Microsoft ODBC pour Oracle est conforme aux spécifications ODBC décrites dans le guide de référence du programmeur ODBC (Version 2.0 ou ultérieure) pour votre système d'exploitation. Ce pilote vous permet de connecter des applications supportant l'ODBC à des bases de données Oracle.


----------------------
Configuration minimale
----------------------

Pour utiliser le pilote Microsoft ODBC pour Oracle, vous devez avoir le logiciel client Oracle, version 7.3 ou ultérieure, installé sur votre ordinateur. Le pilote Microsoft ODBC pour Oracle supporte uniquement la version 2.3 ou une version ultérieure de SQL*Net 2.3. Pour plus d'informations sur les produits Oracle, reportez-vous à votre documentation Oracle.

----------
Nouveautés
----------

Cette version du pilote Microsoft ODBC pour Oracle comprends de nombreuses améliorations au niveau de la stabilité et de la performance. Aucune nouvelle fonction n'a cependant été ajoutée.

Cette version du pilote Microsoft ODBC pour Oracle est plus stable car elle a été testée sur de nombreux systèmes tels que Microsoft Transaction Server et Internet Information Server.
