Rappel pour les utilisateurs occasionnels la consultation des stocks se fait sur : Site = SP-PINON - Magasin = MG-PINON-00
Dans les zones de couleur bleu ou grisé, vous pouvez faire apparaître une liste de choix en appuyant sur F4.
Dans toutes les listes, il est possible de créer un filtre (une requête) avec les raccourcis F2 Shift+F2

 

Saisie d'une commande de sous-traitance :

  1. Saisir les informations d'entête, CDE, Site, Responsable, etc;
  2. Sur la ligne article, saisir un code article ou faire une recherche par F4
  3. Indiquer le lieu de livraison (livré à), Site
    • Site : site de production concerné par la sous-traitance.
    • Magasin : magasin de réception du produit après travail du sous-traitant
    • Mag. sortie : De quel magasin provient la matière première
    • Mag. ST : Dans quel magasin envoyer la matière première.

    Exemple : le site SP-PINON envoi au laquage des profils 
    SITE  : SP-PINON
    MAGASIN : MG-PINON-00
    MAG. SORTIE : MG-PINON-00
    MAG. ST : MG-PINON-ST

  4. Chaque ligne de commande doit comporter une nomenclature de sous-traitance, 
    elle correspond à la matière première à expédier. (Bouton )
    • Article dans la ligne de commande : Article : 00-117_R9005/30_6000
    • Article dans la nomenclature de sous-traitance : Article : 00-117_00_6000
  5. Se positionner sur une ligne à livrer, saisir une date de livraison, une quantité (Multiple de U. Qté), un commentaire
  6. Valider par F5, un numéro de demande est affecté.
  7. Reprendre à l'étape 4 pour saisir un nouvel article.
  8. En fin de saisie, cliquer sur pour éditer la commande.

Consultation / modification d'une commande :

  1. Saisir un numéro de commande ou faire une recherche par F4
  2. Valider par Entrée.
  3. En fin de modification, valider par F5, sinon quitter sans modifier avec F3
