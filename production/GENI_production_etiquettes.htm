notice au format acrobat
Accès : suite à un clic sur depuis l'écran liste des OF ou Affichage d'un OF
Suite au clic, un message de confirmation de la création du fichier étiquette apparaît :

Note 1 : Le nom du fichier correspond au numéro d'OF

Note 2 : Le fichier généré est un fichier texte séparé par des virgules.

 

Conversion du fichier *.eti 

à l'aide de la macro Excel contenue dans Convert_eti_txt.xls

 

Conversion du fichier *.eti

Ouvrir le fichier généré avec Microsoft Excel

  • Choisir Délimité,
  • Cliquer sur Suivant >

  • Choisir Séparateur Virgule,
  • Cliquer sur Suivant >

  • Cliquer sur chaque colonne et choisir Format Texte
  • Suite à la modification de toutes les colonnes, cliquer sur Terminer

Dans le menu Fichier > Enregistrer sous...

  • Choisir le répertoire de sauvegarde
  • Choisir le type de fichier Texte (séparateur : tabulation) (*.txt)
  • Cliquer sur Enregistrer

 

Impression des étiquettes

Utiliser le logiciel Codesoft

  1. Dans le menu « Ficher » , ouvrir le fichier de format d'étiquette suivant : 
    Rép : Etiq.LAB Valider

  2. Dans le menu « Données » , cliquer sur : Ouvrir une base ASCII (F9) 
    La fenêtre principale de la base de données apparaît alors à l’écran 
  3. Dans la zone « fichier de données », chercher le fichier suivant : 
    Rép C:\Etiq\Etiq.Txt (sélectionner et valider)
    Dans la zone « descripteur », chercher le fichier suivant : 
    Rép C:\CS4\DSC\Etiq2.dsc (sélectionner et valider)
    Cliquer sur Valider au bas de la fenêtre après avoir sélectionné les deux répertoires précédents. 
  4. Dans le menu déroulant « Fichier » , cliquer sur : Imprimer
  5. Cliquer sur : Imprimante, vérifier l'imprimante utilisée
    Sélectionner l’imprimante ZEBRA TOOLS et la configurer en « Thermique ».
     
    Cliquer sur Valider
  6. De retour dans la boite de dialogue d'impression

    Cliquer sur « fusion totale » pour lancer l’impression.
