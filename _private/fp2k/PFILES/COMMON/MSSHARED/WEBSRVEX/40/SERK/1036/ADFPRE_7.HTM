Administration à distance

Activation de l'administration à distance sur d'autres serveurs

Lorsque vous utilisez des serveurs autres que IIS, faites appel à l'outil d'administration ou aux fichiers de configuration du serveur pour configurer un nouveau répertoire virtuel pour les formulaires d'administration HTML, et définissez les paramètres de sécurité appropriés. Vous devez activer les formulaires d'administration HTML même si vous employez l'utilitaire de ligne de commande Fpremadm pour l'administration à distance. Vous devez exécuter les formulaires d'administration HTML sur un port sécurisé.

Sur un serveur Windows autre que IIS, les formulaires d'administration HTML sont installés par défaut sur C:\Program Files\Common Files\Microsoft Shared\Web Server Extensions\40\Admincgi. Notez que le répertoire Admcgi n'est pas le répertoire utilisé pour les serveurs IIS, puisque les serveurs non IIS utilisent CGI et non l'interface ISAPI.

Sur un serveur UNIX, les formulaires d'administration HTML sont installés dans le répertoire /usr/local/frontpage/version4.0/admcgi.

Outre la configuration d'une racine virtuelle et des contrôles d'accès appropriés, vous devez octroyer des autorisations d'exécution au sous-répertoire de scripts du répertoire de formulaires afin de lancer l'application CGI qui exécute la commande d'administration sur le serveur.

Pour garantir une connexion sécurisée, les précautions suivantes sont recommandées :

  • Exiger une connexion sécurisée (telle que SSL) pour communiquer avec Fpadmdll.dll ou Fpadmcgi.exe.
  • Fournir un accès à Fpadmdll.dll ou Fpadmcgi.exe avec le système de sécurité du serveur Web. Exiger qu'un utilisateur se connecte sur le serveur Web avec un compte d'administrateur sécurisé évite les accès non autorisés.
  • Exiger l'utilisation d'un port HTTP non standard pour accéder à Fpadmdll.dll ou Fpadmcgi.exe.
  • Utiliser les restrictions de masque d'adresse IP pour éviter que des ordinateurs non autorisés n'accèdent aux formulaires d'administration HTML, Fpadmdll.dll ou Fpadmcgi.exe.
