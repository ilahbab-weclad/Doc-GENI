Architecture de l'administration à distance

Les deux méthodes d'administration à distance des extensions serveur FrontPage, à savoir les formulaires d'administration HTML et l'utilitaire Fpremadm, ont des architectures similaires. Toutes deux communiquent avec un programme sur l'ordinateur serveur : Fpadmdll.dll pour les serveurs IIS et Fpadmcgi.exe pour tous les autres serveurs UNIX ou Windows. Ces programmes appellent à leur tour l'utilitaire d'administration des extensions serveur FrontPage, Fpsrvadm.

L'administration à distance des extensions serveur FrontPage avec l'utilitaire Fpremadm doit être lancée à partir d'un PC client utilisant Windows ou Windows NT. Le PC client doit disposer d'Internet Explorer version 2.0 ou ultérieure. Le client et le serveur communiquent via HTTP avec WinInet. Fpremadm transmet sa ligne de commande à Fpadmdll.dll sur un serveur Web IIS, ou à Fpadmcgi.exe sur tous les autres types de serveurs. Fpadmdll.dll ou Fpadmcgi.exe transmettent à leur tour la commande et les arguments entrants à l'utilitaire Fpsrvadm, qui exécute la commande. Sur l'ordinateur serveur Web, Fpadmdll.dll ou Fpadmcgi.exe servent de programme de traitement de formulaires pour tout formulaire d'administration HTML des extensions serveur FrontPage.
