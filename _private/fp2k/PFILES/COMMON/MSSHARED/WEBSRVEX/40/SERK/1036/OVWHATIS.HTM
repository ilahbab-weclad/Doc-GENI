 4 sur 6   Qu'est-ce qu'un
site Web FrontPage étendu ?

FrontPage traite du contenu sur le World Wide Web en gérant des sites Web FrontPage étendus. Un site Web FrontPage étendu contient toutes les pages Web, les graphismes et les autres fichiers et documents qui constituent un site Web. Les auteurs créent, suppriment, ouvrent et ferment les sites Web FrontPage étendus en utilisant FrontPage sur un ordinateur client. Un site Web FrontPage étendu peut être stocké sur un serveur Web distant ou local. FrontPage permet de copier des sites Web FrontPage étendus d'un serveur Web sur un autre. Vous pouvez également ouvrir et enregistrer des pages d'un site Web FrontPage étendu avec Microsoft Word, Microsoft Excel et les autres applications Microsoft Office 2000.

En plus de ses fichiers, scripts, graphismes et autre contenu, un site Web FrontPage étendu possède :

  • une carte des liens hypertexte de tous ses fichiers,
  • un index de texte intégral de toutes ses pages,
  • une structure persistante que les auteurs peuvent créer et manipuler,
  • un thème Web facultatif,
  • une liste de tâches contenant toutes les tâches à effectuer pour réaliser le site Web FrontPage étendu,
  • des paramètres de sécurité uniques.

 

Sites Web racine et sous-sites Web

Un site Web racine est un site Web FrontPage étendu au sommet du dossier des sites Web d'un serveur Web ou, dans un environnement multi-hôtes, d'un serveur Web virtuel. Son contenu peut être réparti entre plusieurs niveaux de sous-répertoires. Il ne peut y avoir qu'un site Web racine par serveur Web ou serveur Web virtuel.

Un sous-site Web est un site Web FrontPage étendu complet qui constitue un sous-répertoire du site Web racine ou d'un autre sous-site Web. Les sous-sites Web sont le mécanisme de FrontPage qui divise un site Web de sorte que des personnes ou des groupes différents puissent posséder et gérer des zones différentes. Chaque sous-site Web peut comporter plusieurs niveaux de sous-répertoires.

En utilisant des sous-sites Web, vous renforcez automatiquement la sécurité puisque chaque sous-site gère ses propres paramètres de sécurité. De plus, ces sous-sites offrent des performances potentiellement meilleures, car le temps de recalcul des liens hypertexte est directement proportionnel au nombre et à la taille des documents stockés sur un site Web.

Avec les versions précédentes de FrontPage, les sous-sites Web ne pouvaient être créés que directement sous le site Web racine. Avec FrontPage 2000, il est possible de les créer à n'importe quel niveau de la structure du contenu, y compris sous un autre sous-site Web. Dans les grandes organisations, les sites Web sont généralement divisés en zones gérées par des groupes différents. Pouvoir imbriquer autant de sous-sites Web qu'ils le souhaitent donne aux administrateurs Web la souplesse nécessaire pour configurer leurs sites Web d'une façon naturelle et intuitive qui reflète la structure de l'organisation.

Même si les sous-sites Web apparaissent sous d'autres sites Web du système de fichiers et de l'espace URL du serveur Web, le contenu d'un sous-site Web ne fait pas partie de son site Web parent. Un auteur d'un site Web FrontPage étendu ne dispose pas automatiquement des autorisations nécessaires pour modifier ses sous-sites. Cette séparation du contenu est réalisée par les extensions serveur FrontPage.

URL des sites Web FrontPage étendus

Les sites Web étendus FrontPage peuvent être insérés sur un serveur Web et accédés par des navigateurs Web tels que :

  • Noms de domaines privés, comme www.masociété.tld.

    Ceux-ci sont généralement implémentés en tant que serveurs virtuels sur le serveur physique multi-hôtes.

  • Domaine commun ou partagé avec des serveurs virtuels privés, comme dans www.masociété.monfournisseur.tld, où monfournisseur est un domaine partagé et www.masociété un serveur virtuel privé.
  • Une URL sur le serveur d'un fournisseur de services Internet, comme dans www.monfournisseur.tld/masociété.
  • Une URL sur un serveur intranet , comme dans http://frontpage (le site Web racine) http://frontpage/extensions
    (un sous-site Web).
