Installation des extensions serveur FrontPage sur un serveur virtuel

Utilisez ce formulaire pour installer ou mettre à jour les extensions serveur FrontPage sur le port spécifié d'un serveur virtuel. Cette opération exige un nom d'administrateur et un mot de passe.

  1. Dans votre navigateur, démarrez les formulaires d'administration HTML en ouvrant Fpadmin.htm.
  2. Dans le sommaire, cliquez sur New Virtual Server.
  3. Dans le champ Virtual Host Name, tapez le nom de l'hôte virtuel sur lequel vous voulez installer les extensions serveur FrontPage.
  4. Dans le champ Port Number, tapez le numéro du port.
  5. Dans le champ Administrator Account Username, tapez un nom d'utilisateur.

    Sous IIS, cette valeur peut être un nom de compte d'utilisateur ou un nom de groupe Microsoft® Windows NT® et elle peut être qualifiée avec un nom de domaine, par exemple Domaine\Nomutilisateur.

  6. Pour tous les types de serveurs, excepté IIS, tapez le mot de passe du compte d'administrateur dans le champ Administrator Account Password.
  7. Si le serveur possède un fichier de configuration serveur, tapez le chemin d'accès complet à ce dernier dans le champ Server Configuration File Path. Par exemple, sur les serveurs Apache, tapez /usr/local/apache/conf/httpd.conf.
  8. Dans la liste Server Type, cliquez sur le type de serveur Web.
  9. Pour préciser que le contenu du site et les programmes de remplacement des extensions serveur FrontPage doivent changer de propriétaire et être transférés à un compte d'utilisateur UNIX, tapez le nom du compte dans le champ UNIX User Account Username.
  10. Pour préciser que le contenu du site et les programmes de remplacement des extensions serveur FrontPage doivent changer de propriétaire et être transférés à un compte de groupe UNIX, tapez le nom du compte dans le champ UNIX Group Account Name. Notez que même si vous précisez un nom de compte d'utilisateur UNIX, vous n'avez pas à indiquer le nom d'un compte de groupe UNIX.

    Si un nom de compte d'utilisateur ou de groupe est spécifié, les programmes de remplacement des extensions serveur sont accessibles en lecture/écriture et le bit de définition de l'identificateur d'utilisateur désigne le nom d'utilisateur et le nom de groupe indiqué. Notez que seuls les programmes de remplacement des extensions serveur changent de mode, non pas les fichiers de contenu du site.

  11. Cliquez sur Create Server.

 

Les extensions serveur FrontPage sont installées et un site racine est créé.

Création d'un sous-site

Utilisez ce formulaire pour créer un sous-site FrontPage étendu dans le répertoire indiqué, au sein d'un site Web FrontPage étendu existant.

  1. Dans votre navigateur, démarrez les formulaires d'administration HTML en ouvrant Fpadmin.htm.
  2. Dans le sommaire, cliquez sur Create Subweb.
  3. Dans le champ Virtual Host Name, tapez le nom de l'hôte virtuel dans lequel le sous-site doit être créé.
  4. Dans le champ Port Number, tapez le numéro de port du serveur virtuel dans lequel vous créez le sous-site.
  5. Dans le champ Subweb Name, tapez le nom du nouveau sous-site.

    Ce dernier doit correspondre au chemin d'accès d'un répertoire, par rapport au répertoire de premier niveau du serveur.

  6. Dans le champ, Administrator Account Username, tapez un nom d'utilisateur.

    Sous IIS, cette valeur peut être un nom d'utilisateur ou de groupe Windows NT et elle peut être qualifiée avec un nom de domaine, par exemple Domaine\Nomutilisateur

  7. Pour tous les types de serveur, excepté IIS, dans le champ Administrator Account Password, tapez le mot de passe du compte d'administrateur.

    Pour tous les types de serveur, excepté IIS, si les champs Administrator Account Username et Administrator Account Password sont vides, les nouveaux sous-sites héritent des paramètres de sécurité du site racine. Si ces champs ne sont pas vides, le nouveau site possède des autorisations uniques avec un compte d'administrateur et un mot de passe initiaux basés sur le contenu de ces champs.

  8. Pour préciser que la propriété du contenu du site et des programmes de remplacement des extensions serveur doit être transférée à un compte d'utilisateur UNIX, tapez le nom du compte dans le champ UNIX User Account Username.
  9. Pour préciser que la propriété du contenu du site et des programmes de remplacement des extensions serveur doit être transférée à un compte de groupe UNIX, tapez le nom du compte dans le champ UNIX Group Account Name. Notez que même si vous indiquez un nom de compte d'utilisateur UNIX, vous n'avez pas à spécifier un nom de compte de groupe.

    Si un nom de compte d'utilisateur ou de groupe UNIX est indiqué, les programmes de remplacement des extensions serveur sont accessibles en lecture/écriture et le bit de définition de l'identificateur d'utilisateur désigne le nom d'utilisateur et le nom de groupe indiqués. Notez que seuls les programmes de remplacement des extensions serveur changent de mode, non pas les fichiers de contenu du site.

  10. Cliquez sur Create Subweb.

Retrait des extensions serveur FrontPage d'un serveur virtuel

Utilisez ce formulaire pour désinstaller les extensions serveur FrontPage sur le port désigné d'un serveur virtuel. Cette opération désinstalle également les extensions serveur sur les sous-sites du site racine.

  1. Dans votre navigateur, démarrez les formulaires d'administration HTML en ouvrant Fpadmin.htm.
  2. Dans le sommaire, cliquez sur Uninstall.
  3. Dans le champ Virtual Host Name, tapez le nom de l'hôte virtuel.
  4. Dans le champ Port Number, tapez le numéro de port.
  5. Dans la liste Full Uninstall, cliquez sur Yes pour désinstaller les extensions serveur FrontPage sans laisser de méta-informations FrontPage dans le site. Cliquez sur No pour laisser certaines méta-informations FrontPage dans le site. Si vous sélectionnez Yes et réinstallez les extensions serveur FrontPage sur le serveur virtuel, les sous-sites FrontPage ne seront pas recréés automatiquement. Si vous sélectionnez No, les sous-sites présents sur le serveur sont recréés quand vous réinstallez les extensions serveur FrontPage.
  6. Cliquez sur Uninstall.

Contrôle et correction des extensions serveur FrontPage sur un serveur virtuel

Le contrôle des extensions serveur FrontPage englobe les tâches suivantes :

  • Contrôler les autorisations sur les DLL ou exécutables FrontPage.
  • Vérifier l'existence et l'exactitude des répertoires _vti_bin , _vti_pvt, _vti_log etc. créés par FrontPage.
  • Vérifier que les racines virtuelles du serveur et que les paramètres de métabases sont corrects et à jour.
  • Si le site que vous contrôlez comporte des sous-sites, ces derniers sont également vérifiés.

 

  1. Dans votre navigateur, démarrez les formulaires d'administration HTML en ouvrant Fpadmin.htm.
  2. Dans le sommaire, cliquez sur Check and Fix Extensions.
  3. Dans le champ Virtual Host Name, tapez le nom de l'hôte virtuel.
  4. Dans le champ Port Number, tapez le numéro du port.
  5. Cliquez sur Check.

Recalcul des liens hypertexte d'un site

Recalculer les liens hypertexte synchronise les bases de données de contenu FrontPage avec l'état actuel du site. Cette opération réintègre également les pages des composants Insertion de pages, recalcule d'autres composants (comme les formulaires de recherche et les barres de navigation), réapplique les bordures aux pages qui en utilisent, redéfinit les autorisations dans les pages de résultats du programme de traitement des formulaires, réindexe les catégories et recalcule les index de texte.

  1. Dans votre navigateur, démarrez les formulaires d'administration HTML en ouvrant Fpadmin.htm.
  2. Dans le sommaire, cliquez sur Recalculate Links.
  3. Dans le champ Virtual Host Name, tapez le nom de l'hôte virtuel.
  4. Dans le champ Port Number, tapez le numéro du port.
  5. Dans le champ Web Name, tapez le nom du site.

    Ce dernier doit correspondre au chemin d'accès au répertoire de premier niveau du site, par rapport au répertoire de premier niveau du serveur. Pour désigner le site racine, tapez une barre oblique (/).

  6. Cliquez sur Recalculate.

Activation des opérations d'auteur sur un serveur virtuel

Les opérations d'auteur sont activées par défaut dans les extensions serveur FrontPage. Si vous les avez désactivées, vous pouvez néanmoins utiliser ce formulaire pour les activer.

  1. Dans votre navigateur, démarrez les formulaires d'administration HTML en ouvrant Fpadmin.htm.
  2. Dans le sommaire, cliquez sur Enable Authoring.
  3. Dans le champ Virtual Host Name, tapez le nom de l'hôte virtuel.
  4. Dans le champ Port Number, tapez le numéro du port.
  5. Cliquez sur Enable Authoring.

 

Cette opération active également l'administration à distance du site Web FrontPage étendu avec le client FrontPage.

Désactivation des opérations d'auteur sur un serveur virtuel

Les opérations d'auteur sont activées par défaut dans les extensions serveur FrontPage. Utilisez ce formulaire pour les désactiver.

  1. Dans votre navigateur, démarrez les formulaires d'administration HTML en ouvrant Fpadmin.htm.
  2. Dans le sommaire, cliquez sur Disable Authoring.
  3. Dans le champ Virtual Host Name, tapez le nom de l'hôte virtuel.
  4. Dans le champ Port Number, tapez le numéro du port.
  5. Cliquez sur Disable Authoring.

Définition d'autorisations pour un utilisateur

Utilisez ce formulaire pour définir des autorisations FrontPage étendu sur le site Web indiqué.

  1. Dans votre navigateur, démarrez les formulaires d'administration HTML en ouvrant Fpadmin.htm.
  2. Dans le sommaire, cliquez sur User Permissions.
  3. Dans le champ Virtual Host Name, tapez le nom de l'hôte virtuel.
  4. Dans le champ Port Number, tapez le numéro du port.
  5. Dans le champ Web Name, tapez le nom du site.

    Ce dernier doit correspondre au chemin d'accès au répertoire de premier niveau du site, par rapport au répertoire de premier niveau du serveur. Pour désigner le site racine, tapez une barre oblique (/).

  6. Dans le champ Username, tapez le nom de l'utilisateur pour lequel vous ajoutez, supprimez ou modifiez des autorisations.
  7. Pour tous les types de serveurs, excepté IIS, tapez le mot de passe de l'utilisateur dans le champ Password.
  8. Sélectionnez le niveau d'accès de l'utilisateur : Browse Access, Browse and Author Access ou Browse, Author, and Administrate Access. Pour n'accorder aucun accès à l'utilisateur, cliquez sur Remove this User.
  9. Cliquez sur Change Permissions.

Définition d'autorisation pour les adresses IP

Vous pouvez modifier les autorisations pour un ordinateur ou un groupe d'ordinateurs en définissant des autorisations sur les masques d'adresses IP. Un masque d'adresse IP est une série d'adresses IP définie pour que seuls les ordinateurs dont les adresses IP font partie de la fourchette aient le droit d'accéder à un service Internet. Pour masquer une portion d'adresse IP, remplacez-la par le caractère générique astérisque (*). Par exemple, 192.44.*.* représente chaque ordinateur connecté à Internet dont l'adresse IP commence par 192.44.

  1. Dans votre navigateur, démarrez les formulaires d'administration HTML en ouvrant Fpadmin.htm.
  2. Dans le sommaire, cliquez sur IP Address Permissions.
  3. Dans le champ Virtual Host Name, tapez le nom de l'hôte virtuel.
  4. Dans le champ Port Number, tapez le numéro du port.
  5. Dans le champ Web Name, tapez le nom du site.

    Ce dernier doit correspondre au chemin d'accès au répertoire de premier niveau du site, par rapport au répertoire de premier niveau du serveur. Pour désigner le site racine, tapez une barre oblique (/).

  6. Dans le champ IP Address, entrez l'adresse IP de l'ordinateur ou de la série d'ordinateurs pour lesquels vous voulez ajouter, supprimer ou modifier des autorisations. Vous pouvez utiliser l'astérisque (*) en tant que caractère générique, comme dans 128.109.*.*
  7. Sélectionnez le niveau d'accès pour l'ordinateur ou le groupe d'ordinateurs : Browse Access, Browse and Author Access ou Browse, Author, and Administrate Access. Pour supprimer toutes les restrictions liées à l'adresse ou au masque d'adresse IP, cliquez sur Remove this mask.
  8. Cliquez sur Change Permissions.

Fusion d'un sous-site dans son site parent

Utilisez ce formulaire pour désinstaller les extensions serveur sur le sous-site indiqué et sur tous ses sous-sites. Cette opération convertit le sous-site en dossier de son site Web parent FrontPage étendu.

  1. Dans votre navigateur, démarrez les formulaires d'administration HTML en ouvrant Fpadmin.htm.
  2. Dans le sommaire, cliquez sur Merge Subweb.
  3. Dans le champ Virtual Host Name, tapez le nom de l'hôte virtuel.
  4. Dans le champ Port Number, tapez le numéro du port.
  5. Dans le champ Subweb Name, tapez le nom du sous-site.

    Ce dernier doit correspondre au chemin d'accès au répertoire de premier niveau du sous-site, à partir du répertoire de premier niveau du serveur.

  6. Cliquez sur Merge Subweb.

Suppression d'un sous-site

Utilisez ce formulaire pour supprimer le sous-site FrontPage étendu indiqué sur le serveur virtuel et le port indiqués. Vous ne pouvez pas supprimer le site racine avec cette commande. Pour ce faire, utilisez le formulaire Désinstaller.

Ce formulaire supprime la totalité du contenu, y compris les sous-sites du site Web que vous supprimez.

  1. Dans votre navigateur, démarrez les formulaires d'administration HTML en ouvrant Fpadmin.htm.
  2. Dans le sommaire, cliquez sur Delete Subweb.
  3. Dans le champ Virtual Host Name, tapez le nom de l'hôte virtuel.
  4. Dans le champ Port Number, tapez le numéro du port.
  5. Dans le champ Subweb Name, tapez le nom du sous-site.

    Ce dernier doit correspondre au chemin d'accès au répertoire de premier niveau du sous-site, à partir du répertoire de premier niveau du serveur.

  6. Cliquez sur Delete Subweb.

Changement de nom d'un sous-site

Utilisez ce formulaire pour renommer un sous-site.

  1. Dans votre navigateur, démarrez les formulaires d'administration HTML en ouvrant Fpadmin.htm.
  2. Dans le sommaire, cliquez sur Rename Subweb.
  3. Dans le champ Virtual Host Name, tapez le nom de l'hôte virtuel.
  4. Dans le champ Port Number, tapez le numéro du port.
  5. Dans le champ Subweb Name, tapez le nom actuel du sous-site.

    6. Ce dernier doit correspondre au chemin d'accès au répertoire de premier niveau du sous-site, à partir du répertoire de premier niveau du serveur.

  6. Dans le champ New Subweb Name, tapez le nouveau nom du site.
  7. Cliquez sur Rename Subweb.

Comment préciser qu'un dossier peut contenir des programmes

Utilisez ce formulaire pour indiquer qu'un répertoire peut contenir des scripts ou programmes exécutables. Par défaut, les répertoires ne peuvent pas contenir de scripts ou programmes exécutables.

  1. Dans votre navigateur, démarrez les formulaires d'administration HTML en ouvrant Fpadmin.htm.
  2. Dans le sommaire, cliquez sur Set Directory Executable.
  3. Dans le champ Virtual Host Name, tapez le nom de l'hôte virtuel.
  4. Dans le champ Port Number, tapez le numéro du port.
  5. Dans le champ Web Name , tapez le nom du site.

    Ce dernier doit correspondre au chemin d'accès au répertoire de premier niveau du site, par rapport au répertoire de premier niveau du serveur. Pour désigner le site racine, tapez une barre oblique (/).

  6. Dans le champ Directory URL, tapez une URL par rapport au répertoire de premier niveau du site Web FrontPage étendu.
  7. Cliquez sur Set Directory Executable.
