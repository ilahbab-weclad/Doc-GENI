Rappel pour les utilisateurs occasionnels la consultation des stocks se fait sur : Site = SP-PINON - Magasin = MG-PINON-00
Dans les zones de couleur bleu ou grisé, vous pouvez faire apparaître une liste de choix en appuyant sur F4.
Dans toutes les listes, il est possible de créer un filtre (une requête) avec les raccourcis F2 Shift+F2

Pour les articles (alu, tôle, vitrage), il est possible de consulter le stock en cumul
  • pour alu : par numéro de filière, une ligne par teinte avec cumul en mètre
  • pour la tôle : par matière, épaisseur, une ligne par teinte avec cumule en m²
  • pour le vitrage : par chantier, une ligne par composition avec cumul en m²

Détail par éphémère
La liste de tous les éphémères s'affiche
  • pour alu : linéaire de barre (filière / teinte / longueur)
  • pour vitrage  surface de vitrage ( chantier / composition / dimension )
  • pour tôle : surface de tôle ( matière / épaisseur / dimension )
En se positionnant sur une ligne, on peut voir le détail des quantités du stock réel par emplacement et par chantier dans les deux pavés en haut à droite.
  • nombre de barres pour alu
  • nombre de vitrages
  • nombre de tôles
Détail mouvements de stock
L'historique des mouvements des éphémères ou standard affiche les commandes, les livraisons, les entrées, les sorties et les régularisations de l'inventaire permettant d'expliquer la quantité en stock.
