Cette procédure n'est pas utilisée.

BUT : Créer le code article du module à fabriquer.

  • Dans la ligne de commande, à l"emplacement du code article, 
    saisir  MOD ou ECH, cliquer sur ou (Ctrl + 8) pour la création de l'article éphémère.

  • Apparaît une fenêtre de choix de scénario de création, faite votre sélection et validez par OK

  • L'écran de scénario vous demande

    • le code chantier (3 Lettre) ex : PAD pour Paddington

    • le repère de l'article

    • la largeur

    • la hauteur

    • la confirmation de la saisie

    Validez chaque valeur avec la touche Entrée, quand tous les champs sont renseignés, vous retournez dans la commande agence, avec le code article réel.

  • Complétez la ligne de commande avec les informations nécessaires, PU, Poste, Sous-Poste, etc...

Vous pouvez consulter les raccourcis clavier pour vous simplifier la vie...

MOD : Module (demi profilé présent sur les 4 côtés)

ECH : Module en U, en N, en C, autres cas.
