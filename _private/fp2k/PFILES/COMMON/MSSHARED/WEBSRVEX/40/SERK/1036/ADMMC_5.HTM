Composant logiciel enfichable MMC FrontPage

Où trouver les éléments du composant logiciel enfichable MMC FrontPage nécessaires pour administrer les extensions serveur FrontPage

De quel menu, commande, boîte de dialogue ou autre élément du composant MMC FrontPage avez-vous besoin pour effectuer votre tâche, et où le trouver ?

Trois éléments principaux permettent d'administrer les extensions serveur FrontPage :

  • Le menu Nouveau, dans lequel vous pouvez sélectionner des commandes pour créer un site, ajouter un nouvel administrateur, etc., selon ce que vous avez sélectionné dans l'arborescence de la console.
  • Le menu Tâche, dans lequel vous pouvez sélectionner des commandes pour contrôler, corriger, retirer et mettre à niveau les extensions serveur FrontPage, entre autres tâches. Là encore, ce que vous avez sélectionné dans l'arborescence de la console détermine les commandes disponibles dans le sous-menu Tâche.
  • L'onglet Extensions serveur permet de modifier les paramètres des extensions serveur FrontPage, tels que les options de messagerie et les paramètres de sécurité.

 

Le tableau ci-après recense les tâches administratives que vous pouvez effectuer avec le composant logiciel enfichable MMC FrontPage, l'outil à utiliser pour chaque tâche et l'emplacement de cet outil. Les termes entre parenthèses ne s'affichent que si le serveur Web est de type IIS (Microsoft Internet Information Services).
