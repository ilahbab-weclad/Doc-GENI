Kit de ressources des extensions serveur Microsoft FrontPage 2000

Installation des extensions serveur FrontPage sous Windows

Où trouver aux extensions serveur FrontPage

Les extensions serveur FrontPage de tous les serveurs sont disponibles pour téléchargement sur le site http://www.microsoft.com/france/frontpage, et sont incluses dans les produits Microsoft suivants :

  • Microsoft Office 2000 Premium.
  • Microsoft FrontPage 2000.
  • Windows 2000.
  • Elles sont également incluses dans les extensions serveur Office de Microsoft Office 2000 Standard, Professionnel et Premium.

 

Serveurs Web prenant en charge les extensions serveur FrontPage

Sous Windows NT Server et Windows NT Workstation, les serveurs Web suivants prennent en charge les extensions serveur FrontPage :

  • Internet Information Services (IIS) version 3.0 et ultérieure, IIS 5.0 comprise.

    IIS 4.0 nécessite les extensions serveur FrontPage 98 ou ultérieur ; IIS 5.0 nécessite les extensions serveur FrontPage 2000.

  • Netscape FastTrack 2.0, 3.0.1
  • Netscape Enterprise 3.0, 3.5.1
  • O'Reilly WebSite 2.0
  • FrontPage Personal Web Server

 

Sous Windows 95/98, les serveurs Web suivants prennent en charge les extensions serveur FrontPage :

  • Serveur Web personnel Microsoft version 2.0 et ultérieure
  • Serveur Web personnel FrontPage
  • Netscape FastTrack 2.0
  • O'Reilly WebSite 2.0

 

Composants installés

Le programme d'installation des extensions serveur FrontPage met en place les composants suivants :

  • Les fichiers exécutables des extensions serveur FrontPage, les DLL et autres fichiers associés sont installés dans les répertoires C:\Program Files\Common Files\Microsoft Shared\Web Server Extensions\40\Bin et C:\Program Files\Common Files\Microsoft Shared\Web Server Extensions\40\Servsupp.
  • Le composant ISAPI ou CGI qui met en oeuvre les fonctions des extensions serveur sur les sites Web des utilisateurs est installé dans les répertoires C:\Program Files\Common Files\Microsoft Shared\Web Server Extensions\40\Isapi et C:\Program Files\Common Files\Microsoft Shared\Web Server Extensions\40\_vti_bin.
  • Le logiciel enfichable FrontPage de la console de gestion Microsoft, Fpmmc.dll, est placé dans le répertoire C:\Program Files\Common Files\Microsoft Shared\Web Server Extensions\40\_vti_bin.
  • Les utilitaires d'administration par ligne de commande, Fpsrvadm.exe et Fpremadm.exe, sont installés dans le répertoire C:\Program Files\Common Files\Microsoft Shared\Web Server Extensions\40\bin.
  • Le Kit de ressources des extensions serveur FrontPage est un document HTML qui constitue une source d'informations très complète sur les extensions serveur. Il est installé dans le répertoire C:\Program Files\Common Files\Microsoft Shared\Web Server Extensions\40\Serk\nnnn\default.htm. Le dossier \nnnn correspond au nom numérique de la langue d'installation des extensions serveur FrontPage. Pour une installation en langue anglaise des États-Unis, par exemple, le chemin est C:\Program Files\Common Files\Microsoft Shared\Web Server Extensions\40\Serk\1033\default.htm.
  • Les formulaires d'administration HTML sont placés dans les répertoires C:\Program Files\Common Files\Microsoft Shared\Web Server Extensions\40\Admisapi et C:\Program Files\Common Files\Microsoft Shared\Web Server Extensions\40\Admcgi.

 

Installation des extensions serveur FrontPage

La procédure d'installation des extensions serveur FrontPage sur un serveur Web est réalisée en deux temps. Les extensions serveur FrontPage et les programmes et fichiers connexes sont tout d'abord copiés sur votre ordinateur. Les extensions serveur sont ensuite installées dans la zone de contenu de chaque serveur Web et de chaque serveur virtuel mis en place sur l'ordinateur. Cette seconde étape est réalisée automatiquement si vous procédez à une installation sur un ordinateur doté d'un seul serveur Web. Si votre ordinateur possède plusieurs serveurs Web, par contre, vous devez installer les extensions serveur sur chaque serveur à l'aide de l'un des outils d'administration des extensions serveur FrontPage (voir les instructions fournies à l'étape 4 ci-dessous).

Vous devez posséder un compte administrateur sur l'hôte pour exécuter le programme d'installation des extensions serveur FrontPage et copier les extensions serveur sur l'hôte. Il en est de même pour l'installation des extensions serveur FrontPage sur chacun des serveurs Web et des serveurs virtuels.

Sur le CD-ROM Microsoft FrontPage 2000, Servext.exe est le programme d'installation des extensions serveur FrontPage. Les programmes d'installation auto-extractibles correspondant à chaque langue et à chaque type de processeur pris en charge sont disponibles sur le site http://www.microsoft.com/france/frontpage. Ces programmes portent le nom fp00ext_processeur_lang, où processeur désigne le type de processeur et lang désigne le code de trois lettres correspondant à la langue des extensions serveur. Ainsi, le chemin du programme d'installation des extensions serveur FrontPage en allemand pour un processeur Intel série x86 est \ServExt\fp98ext_x86_deu.exe sur le CD-ROM FrontPage.

Pour installer les extensions serveur FrontPage sous Windows :

  1. Exécutez le programme d'installation des extensions serveur à partir du CD-ROM FrontPage ou du site http://www.microsoft.com/france/frontpage.

  2. Pour installer les extensions serveur dans le répertoire par défaut, cliquez sur Installer maintenant. Pour indiquer un autre répertoire de destination, cliquez sur Personnaliser, puis sélectionnez le répertoire.

    Les extensions serveur FrontPage sont installées sur l'ordinateur.

  3. Dans le cas d'une installation ou d'une mise à niveau sur un ordinateur doté d'un seul serveur Web, les extensions serveur FrontPage sont automatiquement installées dans la zone de contenu de ce serveur. Pour le serveur IIS, le compte administrateur initial est le compte administrateur système. Pour tout autre serveur, le programme sollicite un nom de compte administrateur et un mot de passe.

    Dans le cas d'une installation ou d'une mise à niveau sur un ordinateur doté de plusieurs serveurs Web ou serveurs virtuels, vous êtes invité à installer les extensions serveur à l'aide de l'un des outils d'administration des extensions serveur FrontPage énumérés ci-dessous :

    • Logiciel enfichable FrontPage de la console de gestion Microsoft

      • Recourez au logiciel enfichable de la console de gestion Microsoft des extensions serveur FrontPage pour gérer les extensions serveur sur un serveur Web sous Windows NT.

    • Fpsrvadm

      • Utilisez Fpsrvadm à partir de la ligne de commande ou dans les fichiers batch.

    • Formulaires d'administration HTML

      • Utilisez les formulaires d'administration HTML lorsque vous gérez à distance les extensions serveur FrontPage par l'intermédiaire d'un navigateur Web sur tout ordinateur connecté à Internet.

    • Fpremadm

      • Recourez à Fpremadm pour gérer à distance les extensions serveur FrontPage à partir de la ligne de commande ou d'un fichier batch d'un ordinateur tournant sous Windows.

 

Avec FrontPage 2000, un seul jeu de DDL d'extensions serveur FrontPage est installé sur les serveurs IIS. Les versions précédentes de FrontPage copiaient les versions stub de ces programmes dans chaque site et sous-site Web FrontPage étendu. Dans le cas d'une mise à niveau des sites Web FrontPage étendus, le programme d'installation des extensions serveur conserve toutes les autorisations (administrateur, auteur ou navigation uniquement). Les droits d'accès aux fichiers sont seulement modifiés pour préserver ces autorisations. Aux fins de sécurité, les droits d'accès de tout groupe contenant le compte anonyme IUSR_nommachine sont ramenés à la navigation uniquement.
