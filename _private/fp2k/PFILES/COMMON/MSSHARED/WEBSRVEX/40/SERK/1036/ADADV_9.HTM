Activation du contrôle de source intégré sous Windows

Vous pouvez activer le contrôle de source intégré à FrontPage sur tous les serveurs Web pris en charge par FrontPage sous Microsoft Windows NT Server version 4.0 ou ultérieure, Windows NT Workstation version 4.0 ou ultérieure et Windows 95/98.

  1. Dans l'arborescence de la console, cliquez avec le bouton droit de la souris sur le site Web pour lequel vous voulez activer le contrôle de source.
  2. Cliquez sur Propriétés dans le menu contextuel, puis sur l'onglet Publication.
  3. Dans la zone Contrôle de version, cliquez sur Utiliser le contrôle de version standard.
