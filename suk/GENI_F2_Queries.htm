GENI SUK - Queries - last update 18-11-2021

How-to start a query :

  1. Click on or press F2
  2. Fill the columns , you may use the signs % _ to replace caracters. 
  3. Click on or press Shift + F2 to execute the query.

% : matches zero to many caracters (same use as Windows : * )
_ : matches  one caracter (same use as Windows : ? )

Allows you to know the number of data retrieved by the query.

Warning : for some lists your query is case sensitive
bonjour 
BONJOUR
Bonjour

To avoid this guess work, you can force the search to lower case with an advanced search.

Advanced Query :

Sort a column

Create a query with more than one parameter
example : article has  POI or EQU in its code.

For every advanced query you need to name your column
example :     :a    or     :b

Then press Shift+F2 to open the dialog :

Type the SQL command :

examples :

Sort the column named :a  (ASC)
ORDER BY :a ASC
Then click  OK to execute the query.
Use a comma to separate the columns
ORDER BY :a ASC, :b DESC

Findings articles with a code including POI or EQU
:a like '%POI%' OR :a like '%EQU%'
Then clic  OK to execute the query.

It is possible to create a query with the two commands
:a like '%POI%' OR :a like '%EQU%' ORDER BY :a ASC

It is essential to respect the order : filter , order by

In order to avoid case sensitive query you can lower everything

lower(:a) like lower('%POI%')  ORDER BY :a ASC 

 

 
Special case : Date  / Days
Search between two dates

:a between to_date ('01012002','ddmmyyyy') and to_date ('31012002','ddmmyyyy')

Search by date:

:a like to_date ('01012002','ddmmyyyy') 

Any query on a date must be made using the function to_date('date','format'). This allows the database to recognise the input format used.
