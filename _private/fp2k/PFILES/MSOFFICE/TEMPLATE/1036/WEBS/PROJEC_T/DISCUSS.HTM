Cette page contient les liens hypertexte vers tous les groupes de discussion publiques de ce projet. Un site Web protégé séparé est utilisé pour les groupes de discussion et notes internes.

Améliorations

Nous utilisons ce groupe de discussion pour rassembler des suggestions concernant les fonctions devant ou ne devant pas être incluses dans notre logiciel, et engageons un dialogue public sur le bien-fondé de diverses demandes d'amélioration. Toutes les suggestions sont bienvenues.

Base de connaissances

Ce groupe de discussion contient les questions et réponses courantes qui surviennent au cours du travail sur notre projet. Parmi les rubriques appropriées, on trouve les configurations de logiciels ou de matériel, les sources d'utilitaires, et toutes autres informations que les participants au projet ou d'autres personnes travaillant dans un domaine similaire trouveront généralement utiles.
