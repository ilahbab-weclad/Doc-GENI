Kit de ressources des extensions serveur Microsoft FrontPage 2000

 3 sur 6   Présentation des fonctionnalités

Les extensions serveur FrontPage sont un jeu d'applications côté serveur qui permet à plusieurs auteurs de travailler en collaboration sur les mêmes site et serveur Web. Les fonctionnalités de ces extensions sont présentées ci-dessous :

  • Assistance aux auteurs

  • Assistance aux administrateurs

  • Assistance à la navigation

  • Assistance au travail collaboratif

  • Extensions serveur FrontPage et Microsoft Office 2000

 

Assistance aux auteurs

Les extensions serveur FrontPage fournissent les fonctionnalités suivantes aux auteurs de sites étendus FrontPage :

  • Affichage de tous les sites Web FrontPage étendus d'un serveur
  • Ouverture d'un site Web FrontPage étendu en vue d'effectuer des opérations d'auteur
  • Affichage, création et suppression de répertoires
  • Affichage, création, suppression, modification, enregistrement et changement de nom de fichiers
  • Création et configuration de composants de FrontPage

    FrontPage comprend un jeu de composants actifs qui mettent à jour les pages lorsqu'un site Web FrontPage étendu est modifié. Par exemple, le composant Sommaire conserve un sommaire à jour du site Web ; quand un auteur déplace une page, le sommaire est mis à jour. Le composant Insertion de page insère le contenu d'une page dans une autre ; si la page insérée change, toutes les pages qui la contiennent sont mises à jour automatiquement.

  • Affichage, création, application et téléchargement de thèmes

    Un thème se compose d'éléments de dessin et de jeux de couleurs unifiés pour les puces, les polices, les images, les barres de navigation et les autres éléments d'une page. Lorsqu'il est appliqué, un thème confère un aspect attrayant et homogène aux pages et aux barres de navigation d'un site Web. Les auteurs sélectionnent les thèmes d'un site Web dans le mode Thèmes du client FrontPage. Quand le thème d'un site Web FrontPage étendu change, FrontPage met à jour automatiquement chaque page du site avec le nouveau thème.

  • Application de bordures partagées

    Il s'agit de zones de page réservées au contenu dont l'aspect doit être le même sur toutes les pages du site Web FrontPage étendu, comme le numéro de téléphone et l'adresse d'une société. Les bordures partagées contiennent généralement des barres de navigation, c'est-à-dire des liens hypertexte vers d'autres pages du site Web.

  • Définition des méta-informations du site Web et des documents

    Ces méta-informations peuvent être insérées sur les pages à l'aide du composant Insertion de variable.

  • Ajout d'un document à un projet Microsoft Visual SourceSafe, archivage et extraction de ce document
  • Recalcul de la carte des liens hypertexte du site Web FrontPage étendu

    La carte des liens hypertexte du site Web sert à afficher les liens hypertexte dans FrontPage.

  • Création d'un index de texte intégral du site Web

    Le composant Recherche utilise cet index de texte pour rechercher sur le site Web les pages contenant le texte spécifié.

  • Ajout, modification ou suppression d'un élément depuis le mode Tâches

    Le mode Tâches est la liste des tâches à effectuer pour réaliser un site Web FrontPage étendu. Chaque site Web peut avoir sa propre liste de tâches. Quand plusieurs auteurs créent ou modifient un site Web, le mode Tâches peut les aider à savoir qui travaille sur le site et quelles sont les attributions de chaque auteur.

  • Affichage et modification de la structure de navigation d'un site Web FrontPage étendu et création d'intitulés pour les barres de navigation

    La structure de navigation désigne l'ensemble des relations entre les pages d'un site Web FrontPage étendu tel qu'il est défini en mode Navigation. Une structure correctement définie permet à un visiteur de se repérer sur le site. Quand une barre de navigation est insérée sur une page qui fait partie de la structure d'un site Web, FrontPage crée automatiquement des liens hypertexte vers les pages situées sous cette page (pages enfants), au-dessus de cette page (pages parents) et au niveau de cette page dans la structure.

  • Insertion sur les pages des résultats de requêtes de base de données prédéfinies
  • Changement du mot de passe d'un auteur

 

Assistance aux adminsitrateurs

Les administrateurs Web peuvent utiliser le client FrontPage pour administrer un site Web FrontPage étendu, même s'ils ne disposent pas des privilèges d'administration du serveur.

Les extensions serveur FrontPage fournissent les fonctionnalités suivantes aux administrateurs de sites Web :

  • Définition des opérations d'auteur, administration et autorisation de navigation.
  • Création, suppression et modification de nom des sites web FrontPage étendus.
  • Affichage de la liste des utilisateurs ou des groupes d'un serveur Web ou d'un domaine Windows NT.
  • Affichage de la liste des domaines de Windows NT.
  • Ajout de nouveaux auteurs, administrateurs et visiteurs de site (uniquement UNIX).
  • Définition du projet Microsoft Visual SourceSafe pour un site Web.
  • Autorisations uniques ou non pour un site étendu FrontPage.

 

Les extensions serveur FrontPage possèdent un jeu d'outils d'administration qui installent et gèrent les extensions serveur FrontPage sur le serveur Web.

Le composant logiciel enfichable de la console de gestion Microsoft (MMC) des extensions serveur FrontPage enrichit les serveurs virtuels sous Windows et Windows NT en leur ajoutant les extensions serveur FrontPage. En outre, il crée des sites Web, désinstalle les extensions serveur FrontPage, recherche les erreurs sur les sites Web FrontPage étendus et effectue d'autres tâches d'administration via l'interface graphique MMC.

L'utilitaire Fpsrvadm étend les sites ayant les extensions serveur FrontPage et met à jour, supprime et vérifient ces extensions. Cet utilitaire est une application de ligne de commande fonctionnant sous Windows NT et UNIX.

Les formulaires d'administration HTML ont les mêmes fonctionnalités que l'utilitaire Fpsrvadm, mais ils sont implémentés comme un ensemble de formulaires HTML.

L'utilitaire Fpremadm est semblable à Fpsrvadm. Il prend en charge l'administration à distance des extensions serveur FrontPage à l'aide d'un ordinateur client via WinInet.

Assistance à la navigation

Un visiteur d'un site étendu FrontPage qui rencontre un formulaire de recherche, un compteur d'accès, un groupe de discussion ou d'autres fonctionnalités actives, utilise l'assistance à la navigation des extensions serveur de FrontPage. L'assistance à la navigation est mise en oeuvre dans les extensions serveur sous la forme de composant.

Un composant de FrontPage est un objet inséré dans une page HTML à l'aide du programme client FrontPage. Il possède un état fixe codé sous forme de commentaires HTML. Les composants produisent généralement leurs propres résultats HTML qui sont insérés dans la page HTML qui leur est associée. Ils peuvent être exécutés pendant les opérations d'auteur (lorsque le client FrontPage est utilisé) ou pendant la navigation. Par exemple, le composant Insertion de page, qui s'exécute pendant les opérations d'auteur, insère le contenu d'une page dans une autre page.

La liste suivante répertorie quelques-uns des composants exécutables pendant la navigation.

Le composant Formulaire de recherche utilise l'index de texte intégral créé par les extensions serveur. Il se présente comme un formulaire sur une page. Quand un visiteur envoie un formulaire de recherche contenant des mots à localiser, ce formulaire renvoie les liens hypertexte vers toutes les pages du site Web FrontPage étendu qui contiennent ces mots.

Le programme de traitement de formulaire électronique collecte les informations d'un formulaire, les met en forme et les envoie à une adresse électronique.

Le programme de gestion des formulaires de discussion permet aux visiteurs du site de participer à une discussion en ligne. Il collecte les informations à partir d'un formulaire, les met en forme dans une page HTML et ajoute la page au sommaire au à l'index.

Quand un visiteur parcourt une page HTML qui contient un composant FrontPage exécutable pendant la navigation, les extensions serveur effectuent l'opération nécessaire puis génèrent une nouvelle page HTML pour afficher les résultats de l'opération. Par exemple, le formulaire de recherche génère une liste des liens hypertexte en HTML, et le programme de traitement de formulaire électronique génère une page confirmant que le contenu d'un formulaire a été traité et envoyé à une adresse électronique.

Une page HTML sans composants FrontPage de navigation n'utilise pas les extensions serveur lorsqu'un visiteur de site surfe sur une page. Par contre, le procédé d'extraction de page de serveur Web fonctionne.

Assistance au travail collaboratif

La création d'un site Web est une activité collaborative type, en particulier sur un intranet. Les extensions serveur FrontPage gèrent ce processus collaboratif de nombreuses manières.

Tout site Web contenant de nombreux documents stockés dans un ou plusieurs dossiers, il est naturel que plusieurs auteurs travaillent en même sur un site et qu'ils créent, ouvrent, modifient et enregistrent des pages et d'autres fichiers simultanément. Avec la commande Refresh du client FrontPage, les auteurs peuvent mettre à jour leur affichage local du site Web FrontPage étendu pour afficher les modifications éventuellement apportées par d'autres auteurs.

Dans le mode d'affichage de rapports du client FrontPage, il est possible de suivre le contenu d'un site Web FrontPage étendu par niveau d'approbation, auteur assigné ou état de publication. Le client FrontPage génère également des listes de pages pour des catégories standard ou définies par l'utilisateur comme Rapport de frais, Agenda ou Idées.

Par défaut, un auteur essayant d'ouvrir une page déjà ouverte par un autre auteur reçoit un message d'avertissement des extensions serveur FrontPage. Il peut alors ouvrir la page en lecture seule et l'enregistrer en tant que nouvelle page, ou annuler la commande Ouvrir.

Les extensions serveur FrontPage peuvent être configurées pour gérer l'archivage et l'extraction des fichiers d'un site Web FrontPage étendu. Lorsque le site Web est configuré ainsi, il est impossible d'ouvrir un fichier sans l'avoir préalablement extrait. Quand un fichier est extrait, il ne peut pas être ouvert par un autre auteur.

Les extensions serveur FrontPage peuvent être configurées pour gérer l'archivage et l'extraction des fichiers d'un site Web FrontPage étendu à l'aide d'un projet Microsoft Visual SourceSafe. Lorsque le site Web est configuré ainsi et qu'un fichier en est extrait, il est également extrait du projet Microsoft Visual SourceSafe. Cette méthode de contrôle de source permet à un groupe de travail d'exploiter tout le potentiel d'un projet Visual SourceSafe, puisqu'il assure le suivi de tous les changements apportés aux fichiers par les auteurs.

Extensions serveur FrontPage et Microsoft Office 2000

Les extensions serveur FrontPage sont intégrées à Microsoft Office 2000 et, parce qu'elles font partie du serveur Web Office, permettent aux applications Office 2000 d'accéder aux sites Web FrontPage étendus. Quand l'intranet d'une organisation possède un serveur Web Office, les auteurs Office 2000 peuvent enregistrer leurs documents créés avec Word, Excel et d'autres applications Office 2000 directement sur les sites Web FrontPage étendus, et les ouvrir à partir de ces sites.

Lorsqu'un document Word, Excel ou un autre document Office a été ajouté à un site Web FrontPage étendu, en tant que document HTML ou dans un autre format, les extensions serveur FrontPage l'ajoutent à la carte des liens hypertexte de ce site. La fonction de réparation automatique des liens hypertexte de FrontPage devient alors disponible pour le document Office 2000.

Par exemple, quand un document Word ou Excel contenant des liens hypertexte relatifs est placé dans un autre dossier d'un site Web FrontPage étendu, les extensions serveur FrontPage mettent à jour tous les liens hypertexte relatifs de ce document, de sorte qu'ils pointent correctement sur leurs fichiers de destination. Les liens hypertexte rompus sont signalés dans le mode des liens hypertexte du client FrontPage. Quand un site Web FrontPage étendu est publié, tous les liens hypertexte des documents sont mis à jour, y compris ceux des documents Office 2000.

La sécurité des extensions serveur FrontPage est étendue aux auteurs Office 2000. Pour ajouter un document Word, Excel ou un autre document Office à un site Web FrontPage étendu, ou pour l'ouvrir depuis un site Web FrontPage étendu, un auteur doit disposer des autorisations d'opérations d'auteur sur ce site. Quand un document Office a été enregistré sur un site Web FrontPage étendu, il ne peut être visualisé que par les visiteurs autorisés à parcourir ce site.
