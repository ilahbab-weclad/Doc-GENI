Kit de ressources des extensions serveur Microsoft FrontPage 2000

Fpsrvadm

À propos de Fpsrvadm

L'utilitaire Fpsrvadm est une application de ligne de commande pour UNIX et Microsoft® Windows NT®. Il installe les extensions serveur Microsoft® FrontPage® sur les sites Web et effectue toutes les opérations administratives sur les sites FrontPage étendu, qu'il s'agisse de les mettre à jour avec les nouvelles extensions serveur, de désinstaller les extensions serveur ou de contrôler qu'elles sont correctement configurées sur un site Web FrontPage étendu. Fpsrvadm peut être exécuté même lorsque le serveur Web n'est pas opérationnel (le service d'administration de votre serveur Web devra peut-être néanmoins fonctionner).

Fpsrvadm doit fonctionner sur la machine serveur contenant les extensions serveur FrontPage. Pour administrer à distance les extensions serveur FrontPage à partir d'un PC, faites appel à l'utilitaire Fpremadm ou aux formulaires d'administration HTML.

Lorsque vous lancez Fpsrvadm, vous indiquez une opération, sous la forme -operation NomCommande et une série d'arguments de ligne de commande sous la forme -argument valeur. fpsrvadm.exe -operation upgrade -port 80 -multihost sample.microsoft.com

Chaque argument possède une forme abrégée, présentée à la page Arguments de ligne de commande Fpsrvadm. La commande fournie en exemple ci-dessus, devient dans sa forme abrégée :

fpsrvadm.exe -o upgrade -p 80 -m sample.microsoft.com

À titre d'exemple, sur un serveur Web UNIX avec le correctif logiciel FrontPage Apache, vous utiliseriez Fpsrvadm pour installer les extensions serveur FrontPage sur le nouveau serveur virtuel, example.microsoft.com, de la manière suivante :

 
fpsrvadm.exe -o install -p 80 -m example.microsoft.com -u AdminName -pw AdminPassword
    -t apache-fp -s /usr/local/www/apache/conf/httpd.conf 
    -xu UNIXUserName -xg UNIXGroupName

Signification de la commande et des arguments :

  • -o install installe les extensions serveur FrontPage sur le port spécifié d'un serveur virtuel.
  • -p 80 indique le numéro du port.
  • -m example.microsoft.com correspond au nom du domaine du nouveau serveur virtuel.
  • -u AdminName, -pw AdminPassword désignent le nom et le mot de passe de l'administrateur du site FrontPage étendu. Avec le client FrontPage, l'administrateur peut ajouter des auteurs et d'autres administrateurs, ainsi que créer et supprimer des sous-sites FrontPage étendus.
  • -t apache-fp désigne le type de serveur, dans le cas présent le serveur Web doté du correctif logiciel FrontPage Apache.
  • -s /usr/local/www/apache/conf/httpd.conf indique l'emplacement du fichier de configuration du serveur Web.
  • -xu UNIXUserName, -xg UNIXGroupName sont des comptes UNIX. Les extensions serveur FrontPage seront accessibles en lecture/écriture et le bit de définition de l'identificateur d'utilisateur désignera le nom d'utilisateur et le nom de groupe indiqués.
