Dans les zones de couleur bleu ou grisé, vous pouvez faire apparaître une liste de choix en appuyant sur F4.
Dans toutes les listes, il est possible de créer un filtre (une requête) avec les raccourcis F2 Shift+F2

Toutes les zones de couleur bleu ou grisé permettent de faire une recherche par liste de choix (F4).

Appuyer sur F4 pour faire un choix dans la liste complète ou saisir un abrégé complètement ou partiellement puis appuyer sur F4.

ex : recherche d'un article

Saisie de POI dans la zone article de la fiche article
Appui sur la touche F4 du clavier
Une liste de choix contenant tous les articles avec un abrégé contenant POI

Dans la zone Find , il est possible d'affiner la recherche en saisissant une partie de la désignation ou code de l'article recherché. Les caractères génériques % _ peuvent être utilisés.

%  : Tous les caractères
_   : Un caractère

exemple :

%INOX% : Tous les articles contenant le mot inox dans leur code ou désignation
INOX%   : Tous les articles dont la désignation ou le code commence par INOX
%INOX   : Tous les articles dont la désignation ou le code se termine par INOX

Rechercher et se positionner sur la valeur désirée, valider par OK.

Les abrégés

Les abrégés sont généralement codés avec les trois premiers caractères du nom principal (en cas de nom composé l'abrégé est constitué des 3 premiers caractères du premier nom et des 3 premiers caractères du deuxième)

Exemple 1: CH-0120551 GRAND BALLON

la recherche se fait toujours par alpha soit : GRA ou BAL + F4 liste

Exemple 2 : FO-000235 BAUMERT

la recherche se fait toujours par alpha soit : BAU + F4 liste.

Si le N° de la structure est connu on peut taper directement ce numéro.

Pour plus d'information, voir les données techniques
