Rappel pour les utilisateurs occasionnels la consultation des stocks se fait sur : Site = SP-PINON - Magasin = MG-PINON-00
Dans les zones de couleur bleu ou grisé, vous pouvez faire apparaître une liste de choix en appuyant sur F4.
Dans toutes les listes, il est possible de créer un filtre (une requête) avec les raccourcis F2 Shift+F2

Cet écran permet la saisie des temps passés sur les OF

  1. Saisir les informations d'entête
    • Matricule du responsable de la saisie des temps
    • Numéro de lancement et/ou numéro d'OF
    • Code de l'opération
    • Date de réalisation de l'opération << ne pas oublier de renseigner cette date, utilisée dans les états de récap.
    • Matricule de l'opérateur
  2. Une liste d'OF et d'opérations correspondant à la sélection s'affiche,
    • Saisir l'heure de début et l'heure de fin.
    • Saisir le tps réalisé.
    • Saisir le matricule de l'opérateur (F4)
  3. Valider la saisie par F5

Il est possible d'affiner la recherche en exécutant une requête (F2)
