Ameb

Logiciel de mise en barre développé par Axel Rinaldi.

Le logiciel fonctionne avec Microsoft Access 97

Access doit être installé dans le dossier :

C:\Program Files\Microsoft Office\Office

Attention depuis le passage en 64bits des systèmes d'exploitation, le chemin par défaut des installations est "C:\Program Files (X86)"

Astuce : il est possible de créer un lien symbolique pour palier a ce problème

rem créer un lien symbolique vers la version d'access 97 
rem https://www.zebulon.fr/astuces/230-creer-un-lien-symbolique-sous-windows.html 
rem Dans geplog le lien vers access est codé en "dur", il est nécessaire de créer un lien symbolique vers l'emplacement
mklink /J "C:\Program Files\Microsoft Office\Office" "C:\Program Files (x86)\Microsoft Office\Office"

Ameb est installé dans le dossier

C:\Ameb

 

Il est nécessaire de configurer une liaison ODBC vers Ameb.mdb
