Synchronisation d'un site FrontPage étendu avec un projet Visual SourceSafe

Lorsque vous avez installé Microsoft Visual SourceSafe version 5.0 ou ultérieure et défini les comptes d'utilisateur et de groupes qui auront des autorisations pour utiliser le projet Visual SourceSafe, vous devez synchroniser le projet Visual SourceSafe avec votre site FrontPage étendu.

  1. Sous MMC (Microsoft Management Console), dans l'arborescence de la console, cliquez avec le bouton droit sur le site que vous voulez synchroniser avec un projet VSS.
  2. Cliquez sur Propriétés dans le menu contextuel puis sur l'onglet Publication.
  3. Dans la zone Contrôle de version, cliquez sur Usage externe.
  4. Entrez le nom du projet Visual SourceSafe que vous voulez utiliser. Tapez $/ suivi d'un nom de projet, comme $/rootweb.

 

Si le projet n'existe pas dans Visual SourceSafe, il est créé et tous les fichiers du site sont archivés. Si le projet existe, le site FrontPage étendu et le projet sont fusionnés. Tout fichier du site FrontPage étendu dont l'état est ambigu (comme un fichier ayant le même nom qu'un fichier du projet Visual SourceSafe mais n'ayant jamais figuré dans la base de données Visual SourceSafe) reste extrait.

Une fois qu'un site FrontPage étendu est synchronisé avec un projet Visual SourceSafe, tous les fichiers du projet Visual SourceSafe sont affichés dans FrontPage avec un point vert (pour indiquer que le fichier est archivé) ou une coche rouge (pour indiquer que le fichier est extrait).
