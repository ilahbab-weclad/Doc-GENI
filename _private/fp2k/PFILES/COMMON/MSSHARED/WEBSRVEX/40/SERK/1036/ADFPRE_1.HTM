Administration à distance

À propos de Fpremadm

L'utilitaire Fpremadm permet d'administrer à distance les extensions serveur Microsoft® FrontPage® à partir d'un PC Microsoft® Windows®. Son interface s'inspire de l'utilitaire d'administration des extensions serveur FrontPage, Fpsrvadm et propose les mêmes commandes. Fpremadm exige que Microsoft Internet Explorer, version 2.0 ou ultérieure, soit installé sur l'ordinateur client. Il n'existe pas de version UNIX de cet utilitaire. Vous pouvez néanmoins l'utiliser à partir d'un client Windows pour administrer les extensions serveur FrontPage sur des serveurs Web UNIX.

Fpremadm utilise le même programme CGI ou ISAPI côté serveur que les formulaires d'administration HTML : Fpadmdll.dll sur les serveurs IIS et Fpadmcgi.exe sur tous les autres serveurs. C'est pourquoi vous devez installer et activer les formulaires d'administration HTML sur le serveur que vous voulez administrer avant d'utiliser Fpremadm.

Lorsque vous utilisez Fpremadm, vous formez la ligne de commande de la même façon qu'avec l'utilitaire Fpsrvadm, en ajoutant les arguments Fpremadm comme dans la commande Upgrade suivante :

fpremadm.exe -adminusername CompteUtilisateur -adminpassword
-targetserver https://sample.microsoft.com:1439/fpadmin/scripts/fpadmdll.dll
-o upgrade -p 8234 -m sample.microsoft.com

Remarquez l'utilisation d'une connexion sécurisée et d'un port non standard.

Outre la prise en charge du même jeu de commandes que Fpsrvadm, Fpremadm contient les arguments supplémentaires suivants pour établir la connexion au serveur distant :

 

Argument Description Exemple
-targetserver URL complète du programme d'administration côté serveur, Fpadmdll.dll sur les serveurs IIS et Fpadmcgi.exe sur tous les autres serveurs. Chaîne URL telle que :

https://sample.microsoft.com/fpadmin/
scripts/fpadmcgi.exe

Pour les serveurs Web IIS et Microsoft Personal Web Server, l'URL a la forme suivante :

https://sample.microsoft.com/fpadmin/
scripts/fpadmdll.dll
-adminusername Nom d'utilisateur à authentifier pour accéder au programme d'administration. Il est différent de l'argument -username. C'est le nom d'utilisateur utilisé pour se connecter et avoir accès à Fpadmdll.dll ou Fpadmcgi.exe. Nom d'utilisateur, tel que :

compteutilisateur

Peut être laissé vide si vous utilisez
l'authentification Stimulation/
Réponse de Windows NT®.
-adminpassword Mot de passe à utiliser pour authentifier l'accès au script d'administration. Il est différent de l'argument -password. C'est le mot de passe utilisé pour se connecter et avoir accès à Fpadmdll.dll ou Fpadmcgi.exe. Mot de passe, tel que :

787abC

Peut être laissé vide si vous utilisez l'authentification Stimulation/Réponse de Windows NT®.

 

Pour une description complète de toutes les commandes disponibles avec Fpremadm, voir Fpsrvadm.
