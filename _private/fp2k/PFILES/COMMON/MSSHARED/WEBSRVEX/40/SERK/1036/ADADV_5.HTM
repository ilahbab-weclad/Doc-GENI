Présentation du contrôle de source des extensions serveur

Les extensions serveur Microsoft® FrontPage® offrent un contrôle de source intégré et le contrôle de source Microsoft® Visual SourceSafe™ (VSS). Elles fonctionnent avec une version 5.0 ou ultérieure de Visual SourceSafe. Lorsque l'une ou l'autre méthode de contrôle de source est activée, les auteurs peuvent utiliser des commandes de FrontPage pour contrôler les pages et autres fichiers à l'intérieur et à l'extérieur d'un site Web FrontPage étendu. Lorsque le contrôle Visual SourceSafe est activé, les auteurs bénéficient de fonctionnalités avancées comme le suivi et la consignation des modifications de chaque fichier, la consultation de l'historique d'un fichier et le retour à des versions antérieures d'un fichier.

Quel que soit le contrôle de source activé, les extensions serveur FrontPage effectuent des extractions et des archivages en arrière-plan une fois certaines opérations effectuées dans FrontPage. À titre d'exemple, quand un thème est appliqué à un site dont le contrôle de source est activé, chaque page inutilisée est extraite en arrière-plan, le nouveau thème est appliqué et la page est archivée. En procédant ainsi, les extensions serveur FrontPage protègent la cohérence d'un site et permettent d'éviter qu'il ne contienne des erreurs telles que des liens hypertexte rompus.

Le tableau suivant illustre comment les extensions serveur FrontPage implémentent le contrôle de source pour des opérations courantes, sur page ou sur site :

 

Lorsqu'un auteur… Les extensions serveur… Sauf si
Édite et enregistre une page qui n'a pas été extraite Extraient la page, la mettent à jour, et la réincorporent dans le site et dans le projet VSS (si le contrôle VSS est activé).
Déplace un fichier Déplacent le fichier dans le site et dans le projet VSS (si le contrôle VSS est activé). Elles extraient ensuite chaque page du site contenant un lien hypertexte au fichier déplacé, mettent à jour tous les liens hypertexte à ce fichier et réarchivent chaque page. Une page contenant un lien hypertexte au fichier déplacé est extraite. Dans ce cas FrontPage ne permet pas à l'auteur de déplacer le fichier.
Renomme un fichier Renomment le fichier dans le site et dans le projet VSS (si le contrôle VSS est activé). Elles invitent ensuite l'auteur à extraire chaque page du site contenant un lien hypertexte au fichier déplacé, à mettre à jour tous les liens hypertexte à ce fichier et à réarchiver chaque page. Une page contenant un lien hypertexte au fichier renommé est déjà extraite. Dans ce cas, FrontPage ne permet pas à l'auteur de renommer le fichier.
Supprime un fichier Suppriment le fichier dans le site et dans le projet VSS (si le contrôle VSS est activé). Le fichier est extrait. Dans ce cas, FrontPage ne permet pas à un auteur de supprimer le fichier.
Importe un fichier Archivent le fichier dans le site et dans le projet VSS (si le fichier est nouveau, le contrôle VSS est activé). Si le fichier existe déjà dans le site, les extensions serveur l'extraient, le mettent à jour et le réarchivent dans le site et dans le projet de contrôle VSS.
Crée une page Archivent la page dans le site et dans le projet VSS (si le contrôle VSS est activé).
Édite et enregistre une page ou un graphisme inclus dans d'autres pages Tentent d'extraire toutes les pages du site comprenant la page ou le graphisme, mettent à jour toutes les pages et réarchivent chaque page dans le site et dans le projet VSS (si le contrôle VSS est activé). Une page contenant la page ou le graphique est déjà extraite. Dans ce cas, FrontPage ne procède pas à la mise à jour de la page. Pour mettre à jour toutes les pages, faites en sorte que tous les auteurs archivent toutes les pages, puis utilisez la commande Recalculer les liens hypertexte.
Applique un thème à un site Tentent d'extraire toute page du site Web qui utilise le thème par défaut du site, mettent à jour toutes les pages et les réarchivent dans le projet VSS (si le contrôle VSS est activé). Une page qui utilise le thème par défaut est déjà extraite. Dans ce cas, FrontPage n'applique pas le thème à la page. Pour mettre à jour toutes les pages, faites en sorte que tous les auteurs les réarchivent, puis réappliquez le thème au site.
Édite et enregistre une bordure partagée Tentent d'extraire chaque page du site contenant la bordure partagée, mettent à jour toutes les pages et les réarchivent dans le site et dans le projet VSS (si le contrôle VSS est activé). Une page utilisant une bordure partagée est déjà extraite. Dans ce cas, FrontPage ne procède pas à la mise à jour de la bordure partagée. Pour mettre à jour toutes les pages, faites en sorte que tous les auteurs les réarchivent, puis supprimez et réappliquez les bordures partagées au site avec la commande Bordures partagées.
