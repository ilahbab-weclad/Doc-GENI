Saisir les types de façade
et types de produit d'un chantier

Accessible depuis :
  • le menu : Structure > Lien typologies / produits
  • l'écran de la Fiche Structure, bouton

Cet écran permet de saisir les informations en provenance du commercial ou de l'étude technique.

C'est le budget initial , les quantités prévues de produits à acheter / fabriquer.

Ex : 500 modules,    1000 ml de couvertine ou  200 m² de couvertine.

Le trigramme du chantier  associé au couple code de typologie et code de produit formera le début du numéro des commandes.

Saisir le code chantier   CH-xxxx ou le rechercher dans la liste de choix (F4) puis valider

 

Typologie (type de façade)

Saisir une typologie  : code numérique de 2 caractères

Un libellé, une surface, le budget global de cette typologie

La partie budget Total sera renseignée automatiquement si vous décomposer le budget dans les Type produit.

 

Type(s) Produit(s)

Saisir un code de produit :  code numérique de 2 caractères

ou utiliser la liste sur la gauche.
Cette liste vous permet, de faire une sélection par une liste, surlignés le code de votre choix et cliquez sur les boutons magnéto pour transférer votre choix d'un côté à l'autre. 

Cliquez sur le bouton Valider pour enregistrer votre sélection.

astuce : Vous pouvez également faire un filtre sur la dizaine et réduire la liste présentée.

Lorsque les codes produits sont dans la liste de gauche

Vous pouvez renseigner le budget.

Vous devez obligatoirement saisir une Qté et une Unité      (si vous ne connaissez pas la Qté d'un produit, mettre 0  (zéro) )

 

Type d'ETU et chiffrage de la Main d'Oeuvre

Le paramétrage doit être également poursuivi dans le menu Structures >fiche Structure > Type d'ETU par chantier

Type ETU : typologie    (ajouter un A pour les angles)

Surface : Surface globale de la typologie (trouvée dans le dossier transfert)

Temps : Temps de MO usine en heures /  m² (trouvé dans le transfert)
note : selon le découpage du transfert, il peut etre nécessaire d'ajouter les temps de tôlerie.

Le type ETU est le temps permettent de chiffrer la MO pour l'usine.

GENI calcule un temps selon les articles présents dans la nomenclature, et ce temps est ajusté selon le paramétrage du type ETU.
L'opération de gamme FFM récupère ce delta.
Ce mode de calcul fonctionnement a été demandé par DKN.

Par convention,
Le temps paramétré pour le type MAQ - maquette est 3x le temps  prévu pour les modules standards
Le temps paramétré  pour les angles est 2x le temps prévu pour la typologie.
