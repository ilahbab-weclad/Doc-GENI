Saisie / Modif Réservation

Cet écran permet de saisir une réservation

Créer une nouvelle réservation

  1. Saisir un N° Résa non existant puis valider par Entrée
    le  logiciel vous demande confirmation de la création
  2. Cliquer sur pour ajouter les ETU ( Eléments Terminés Usine )
  3. Cliquer sur pour calculer les besoins de la réservation
  4. Cliquer sur pour éditer les besoins bruts > Chgt d’état de la réservation

Consulter / Modifier une réservation

  1. Saisir le N° Résa puis valider par Entrée
  2. Cliquer sur pour modifier la réservation
  3. Cliquer sur pour éditer les besoins bruts
