Composant logiciel enfichable MMC FrontPage

À propos du composant logiciel enfichable MMC FrontPage

Le composant logiciel MMC Microsoft® FrontPage® est un programme tournant exclusivement sous Microsoft® Windows NT® qui permet d'administrer les extensions serveur FrontPage et les sites Web FrontPage étendu. Vous pouvez l'utiliser, entre autres, pour étendre des serveurs virtuels, créer des sous-sites Web, mettre à niveau les extensions serveur d'un site, convertir des dossiers en sous-sites Web et vice-versa, recalculer les liens hypertexte d'un site, etc.

Le composant logiciel MMC FrontPage « s'enfiche » dans la console de gestion MMC (Microsoft Management Console), ce qui signifie que les commandes, les feuilles de propriétés et autres outils dont vous avez besoin pour administrer les extensions serveur FrontPage sont ajoutés au « shell » MMC. Qui plus est, les outils du composant logiciel enfichable MMC FrontPage sont similaires aux autres outils de la console et fonctionnent de la même façon.

Si Microsoft Internet Information Services (IIS) version  4.0 ou ultérieure est installé sur un ordinateur, le composant logiciel MMC FrontPage « s'enfiche » dans le composant logiciel enfichable IIS. C'est-à-dire que ses fonctionnalités s'ajoutent à celles du composant enfichable du Internet Service Manager IIS. Si un serveur Web autre que IIS version  4.0 ou ultérieure est installé, les fonctionnalités du composant logiciel enfichable MMC s'ajoutent directement à la console et s'appelle l'Administrateur des extensions serveur. Tous les outils nécessaires pour gérer un site Web sont regroupés à un seul et même emplacement pratique.

Le composant logiciel enfichable MMC FrontPage remplace avantageusement l'utilitaire Fpsrvwin, un programme d'administration inclus dans les versions précédentes de FrontPage. Il permet d'effectuer la plupart des tâches administratives réalisables avec les utilitaires Fpsrvwin, Fpsrvadm et Fpremadm, plus quelques tâches supplémentaires.
