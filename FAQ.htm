GENI Usine - Geni Agence

Rappel pour les utilisateurs occasionnels

La consultation des stocks se fait sur : Site = SP-PINON - Magasin = MG-PINON-00

Dans les zones de couleur bleu ou grisé, vous pouvez faire apparaître une liste de choix en appuyant sur F4.

Dans toutes les listes, il est possible de créer un filtre (une requête) avec les raccourcis F2 Shift+F2  

Clavier dans une autre langue

Question :
Les lettres affichées à l'écran ne correspondent pas au clavier

Réponse : 
Vous avez certainement, par le biais d'une combinaision de touches, changer la configuration de votre clavier
Appuyer sur Alt + Shift(Gauche) pour changer la configuration

Ecran de consultation

(exemple : Fiche article, Fiche structure, etc...)

Question :
Je consulte une fiche article dans GENI, je désire en afficher une autre, comment faire ?

Réponse : 
Appuyer sur F3 (quitter), le curseur se positionne sur le premier champ, taper un nouveau code ou un nouvel abrégé dans la zone article et appuyer sur F4 pour sélectionner l'article dans la liste de choix.

Export vers...

Question : 
Qu'est-ce que le fichier GEP_EXP.XLS ?

Réponse :
C'est le nom du fichier temporaire sous lequel tout export vers Excel est fait.
N'oubliez pas de renommer ce fichier si vous désirez sauvegarder le résultat de votre export. (Sous excel : Fichier > Enregistrer sous... ) 

 

Question :
Je viens de lancer un export vers Excel, mais Excel ne s'ouvre pas automatiquement où est sauvegarder le fichier temporaire ?

Réponse : 
Le fichier généré se trouve sous : C:\GEP_LOG\REQUETE\
sous le nom : GEP_EXP.XLS

Documentation en ligne

Question :
Sous Internet Explorer, je souhaite consulter deux pages simultanément. Ma page courante et la page désignée par un lien.

Réponse : Au moment de cliquer sur le lien, appuyer sur la touche Shift ( majuscule). Ou cliquer sur le bouton droit de la souris et choisissez 'Ouvrir dans une nouvelle fenêtre'

 

Impression

Problème :
Lors de l'impression des pages de l'intranet, les phrases longues ne s'impriment pas complètement, le texte est coupé à droite.

Solution :
Essayer de changer la taille d'affichage du texte.
Sous Internet Explorer choisir dans le menu Affichage > Taille du Texte > La plus petite
