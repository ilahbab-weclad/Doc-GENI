Rappel pour les utilisateurs occasionnels la consultation des stocks se fait sur : Site = SP-PINON - Magasin = MG-PINON-00
Dans les zones de couleur bleu ou grisé, vous pouvez faire apparaître une liste de choix en appuyant sur F4.
Dans toutes les listes, il est possible de créer un filtre (une requête) avec les raccourcis F2 Shift+F2
Exemple :
  • FAQ : Trouver les tôles créées pour un chantier et trier par ordre alpha 
  • FAQ : Trouver un code article gpao selon un repère agence 
  • FAQ : Trouver sans tenir compte de la casse minuscule / majuscule
  • Tutoriel en vidéo
 

Pour lancer une requête :

  1. Cliquer sur ou appuyer sur F2
  2. Renseigner les champs connus, il est possible d’utiliser les caractères génériques % _ pour remplacer ceux figurant à la même position. 
  3. Cliquer sur ou appuyer sur Shift + F2 pour exécuter la requête, si une erreur apparaît, un message d’avertissement apparaît.

% : représente plusieurs caractères (équivalent sous Windows : * )
_ : représente un seul caractère (équivalent sous Windows : ? )

Requête avancée :

Trier une colonne par ordre alphabétique

Filtrer les enregistrements avec plusieurs paramètres
exemple : code article contient POI ou EQU

Pour toute requête avancée, nommer le champ à traiter
exemple :     :a    ou     :b

puis appuyer sur Shift+F2 pour faire apparaître la boite de dialogue suivante :

Saisir la commande SQL correspondant à votre demande :

exemples :

Trier le champ désigné par :a dans l'ordre croissant (ASC)
ORDER BY :a ASC
puis cliquer sur OK pour lancer la requête.
en cas de tri multiple, séparer les champs par une virgule
ORDER BY :a ASC, :b DESC

Rechercher les article dont le code contient POI ou EQU
:a like '%POI%' OR :a like '%EQU%'
puis cliquer sur OK pour lancer la requête.

Il est possible de créer une requête associant les deux demandes
:a like '%POI%' OR :a like '%EQU%' ORDER BY :a ASC

Note : Il est indispensable de respecter l'ordre :
critère de choix, critère de tri.

Pour ne pas avoir a respecter la casse min/maj, forcer la requête en minuscule 
en ajoutant la fonction lower()
lower(:a) like lower('%POI%')  ORDER BY :a ASC

Cas particulier : Gestion des dates
Recherche entre deux dates

:a between to_date ('01012002','ddmmyyyy') and to_date ('31012002','ddmmyyyy')

Recherche sur une date

:a like to_date ('01012002','ddmmyyyy') 

Recherche après ou avant une date

:a >= to_date ('01012002','ddmmyyyy') 

:a <= to_date ('01012002','ddmmyyyy') 

Toute interrogation sur une date doit être faite en utilisation la fonction to_date('date','format'). Cela permet à la base de donnée de reconnaître le format d'entrée utilisé.

 

Cas particulier : Rechercher tous les articles créés à partir d'une liasse de saisie graphique ou d'une donnée technique manuelle
Depuis l'écran liste des articles, 
  1. lancer une requête F2
  2. Dans la colonne Article, saisir :A
  3. Lancer la requête Shift+F2
  4. Dans l'éditeur de Query/Where saisir sce_no_session=-numéro_liasse
  5. Valider par OK

Note tous les articles créé à partir d'une liasse ou d'une DT manuelle possèdent un numéro de session.
exemples :

  • pour trouver les articles créés à partir de la liasse 9876, il faut saisir sce_no_session= -9876
  • pour trouver les articles créés à partir de la DT 123456, il faut saisir sce_no_session= -123456  

(Ne pas oublier le signe négatif)

Cas particulier : La liste des articles en stock MG-PINON-00
Depuis l'écran liste des articles,
  1. lancer une requête F2
  2. Dans la colonne Article, saisir :A
  3. Éventuellement choisissez une famille ou sous famille  (ex : REM   VIT)
  4. Dans l'éditeur de Query/Where saisir
    :a in (select article from stocks where soc='4' and magasin='MG-PINON-00' and sto_rel > 0)
  5. Valider par OK
