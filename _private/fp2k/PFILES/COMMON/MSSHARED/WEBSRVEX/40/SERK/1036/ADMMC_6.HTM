Fonctionnement du composant logiciel MMC FrontPage avec différents serveurs Web

Si vous travaillez avec Microsoft Internet Information Services (IIS) et avec d'autres serveurs Web  — comme WebSite ou Netscape — vous avez peut-être remarqué que le composant logiciel MMC FrontPage ne fonctionne pas de la même façon avec IIS version 4.0 ou ultérieure qu'avec les autres serveurs Web, y compris IIS 3.0.

IIS est doté d'un composant logiciel qui s'enfiche dans la console MMC (Microsoft Management Console). Le composant logiciel MMC FrontPage est conçu de manière à s'intégrer au composant logiciel enfichable de IIS version 4.0 ou ultérieure. Si IIS est installé sur un ordinateur, les fonctionnalités du composant enfichable FrontPage sont entièrement intégrées à celles de IIS. Si vous avez travaillé avec le composant MMC IIS auparavant, vous remarquerez peut-être que certaines commandes ont été ajoutées au menu Action et aux menus contextuels, et qu'une page de propriétés a été intégrée à la feuille de propriétés pour les extensions serveur. Le composant logiciel MMC FrontPage a ajouté cette nouvelle fonctionnalité. En cas de chevauchement de fonctionnalité, c'est la commande IIS qui apparaît et non la commande du composant enfichable FrontPage. Dans l'arborescence de la console, IIS affiche la liste de tous les sites Web IIS, qu'il s'agisse de sites Web FrontPage ou d'autres sites Web.

Si le composant logiciel enfichable FrontPage MMC est installé avec un serveur Web autre que IIS version 4.0 ou ultérieure, ses fonctionnalités ne sont pas intégrées à celles du serveur Web. En fait, le serveur peut même ne pas comporter de composant logiciel enfichable MMC ajoutant ses fonctionnalités à la console. Dans ce cas, l'arborescence de la console ne recense que les sites Web FrontPage. Elle ne liste pas tous les sites Web présents sur l'ordinateur.

Il arrive que des serveurs Web IIS et autres cohabitent sur le même ordinateur. Dans ce cas, vous voyez l'élément de premier niveau de chaque serveur Web, avec ses sites Web listés en dessous. Lorsque vous sélectionnez un site Web présent sur le serveur Web IIS puis affichez le menu contextuel, vous voyez les commandes du composant logiciel IIS et celles du composant logiciel FrontPage. Lorsque vous sélectionnez un site Web présent sur le serveur non IIS, puis affichez le menu contextuel, les commandes d'administration des extensions serveur FrontPage ne sont complétées que par le composant enfichable MMC FrontPage.
