 9 sur 10     Fichier de configuration des extensions serveur

Certains paramètres de sécurité des extensions serveur FrontPage peuvent être contrôlées dans le fichier de configuration des extensions serveur. Ce fichier réside dans /usr/local/frontpage et s'appelle wexxxx.cnf ou, sur les serveurs multi-hôtes, hôte:xxxx.cnf, où xxxx désigne le numéro du port de votre serveur et hôte le nom ou l'adresse IP du serveur. Le fichier de configuration global /usr/local/frontpage/version4.0/frontpage.cnf contient les paramètres par défaut qui s'appliquent à tous les sites Web FrontPage étendus.

Pour obtenir la liste complète de ces derniers et de tous les autres paramèttres des extensions sereveur, reportez-vous à l'annexe Variables de configuration des extensions serveur FrontPage.
