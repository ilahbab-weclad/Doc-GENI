Dans les zones de couleur bleu ou grisé, vous pouvez faire apparaître une liste de choix en appuyant sur F4.
Dans toutes les listes, il est possible de créer un filtre (une requête) avec les raccourcis F2 Shift+F2

Création d’une fiche matricule

Aller dans l’écran Pointage > Fiche matricule

Saisir le matricule : 
Pour un salarié Rinaldi Structal : le matricule est attribué par le service ressources humaines.
Pour un intérimaire : Utiliser le code suivant : I-NNN-PPP avec

NNN les trois premières lettres du NOM et 
PPP les trois premières lettres du prénom

Renseigner les zones restantes

Enregistrer la fiche par F5
Quitter l’écran par F3

Édition du badge de pointage

Aller dans l’écran Pointage > Liste matricules

Rechercher la ou les fiches créées avec une requête F2.
Ou en se déplaçant dans la liste avec les touches de direction

Aller dans le menu Touches, vous avec le choix entre 

  • Éditer le badge du matricule
  • Éditer badges de toute la liste
