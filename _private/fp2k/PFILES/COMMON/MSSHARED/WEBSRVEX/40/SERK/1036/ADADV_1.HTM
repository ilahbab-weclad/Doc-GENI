Configuration des options de messagerie sous Windows

Le programme client Microsoft® FrontPage® permet de configurer un formulaire dont le contenu peut ensuite être envoyé sous forme de message électronique. Pour qu'un message puisse être envoyé à partir d'un serveur Web, un administrateur doit configurer les extensions serveur de façon à délivrer le courrier électronique à un transport de messagerie.

Pour définir les paramètres des extensions serveur sur des serveurs Windows®, procédez selon l'une des méthodes ci-dessous :

  • Si vous utilisez un transport de messagerie SMTP, faites appel au composant logiciel enfichable MMC FrontPage pour définir votre transport de messagerie.
  • Si vous utilisez un transport de messagerie Sendmail, définissez les paramètres de messagerie dans l'Éditeur de registres. Vous pouvez également configurer un transport SMTP avec l'Éditeur de registres.

 

Les paramètres de registre des extensions serveur d'un port figurent à la sous-clé \HKEY_LOCAL_MACHINE\SOFTWARE\MICROSOFT\SHARED TOOLS\WEB SERVER EXTENSIONS\PORTS\port. Pour consulter un tableau des paramètres de registre configurés par les extensions serveur, reportez-vous à l'annexe Variables de configuration des extensions serveur FrontPage.

FrontPage fournit cinq sous-clés de registre pour configurer votre transport de messagerie : SMTPHost, SendMailCommand, MailSender, MailCharSet et MailEncoding. Vous devez configurer SMTPHost ou SendmailCommand, mais pas les deux.

Le tableau suivant illustre comment configurer ces paramètres :

 

Variable Définition Exemple
SMTPHost Nom ou adresse IP d'un hôte utilisant un serveur ou un démon SMTP. Lorsqu'un visiteur de site soumet un formulaire dont les résultats doivent être envoyés par courrier électronique, les extensions serveur établissent une connexion au serveur SMTP pour délivrer le message. Par défaut, FrontPage considère que le serveur est sur le port 25 (standard pour SMTP), mais vous pouvez définir un autre port en ajoutant :xx à la suite du nom, où xx désigne le port à utiliser. mail.example.microsoft.com,

test:10000,

127.0.0.1
SendMailCommand Nom d'un programme sur la machine serveur vers laquelle le courrier électronique doit être acheminé. Si SendMailCommand et SMTPHost sont tous deux configurés, SendmailCommand est prioritaire.

Lorsque les extensions serveur FrontPage reçoivent un formulaire traité sous forme de courrier électronique, elles lancent la commande en remplaçant toutes les occurrences de %r par le destinataire du courrier. Le caractère de pourcentage (%) suivi d'un caractère quelconque est remplacé par ce caractère.

 sendmail %r
MailSender Nom à utiliser comme compte « expéditeur » pour l'envoi de courrier électronique. Plus spécifiquement, il est utilisé comme argument de la commande SEND FROM: sous SMTP. Sous SMTP, le nom par défaut est utilisateur@hôte, où utilisateur désigne l'utilisateur actuel et hôte le nom de l'hôte en cours. example@microsoft.com
MailCharSet Pour annuler l'attribut de jeu de caractères de l'en-tête de type contenu, indiquez le jeu de caractères ici.  
MailEncoding Permet d'annuler l'attribut de codage du transfert de contenu pour l'en-tête de type contenu. Vous pouvez changer de schéma de codage si vous savez qu'un destinataire de courrier électronique utilise un schéma de codage différent et ne peut pas interpréter vos messages.
