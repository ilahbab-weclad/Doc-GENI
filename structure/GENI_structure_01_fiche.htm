Dans les zones de couleur bleu ou grisé, vous pouvez faire apparaître une liste de choix en appuyant sur F4.

Cet écran permet de consulter, créer ou modifier une structure.

Affichage d’une fiche structure

  1. Saisir le début de l'abrégé dans la zone Structure puis appuyer sur F4
    Choisir dans la liste    , valider par entrée ou OK
    Affichage du code structure complet
    Valider par ENTREE
  2. Affichage de la fiche structure complète
    Affichage des compléments : Propriété, ...
  3. Modifier la fiche si nécessaire, valider les changements (F5) 
    ou quitter sans sauvegarder (F3)

Création d'une structure

Deux méthodes sont applicables pour la création d'une structure

  • Afficher une structure existante (même classe), le dupliquer , saisir un nouveau code structure, si le code existe déjà un message d'erreur apparaîtra, sinon modifier les champs nécessaires : Abrégé, Désignation, Propriétés, etc.

  • Depuis une fiche structure vierge, saisir une référence dans structure, passer au champ suivant, le système vérifie si la référence existe, si non, saisir l'abrégé, puis les autres champs.

Valider la création en cliquant sur ou en appuyant sur F5.

Gestion des contenants (CNT)

Développement spécifique pour les écrans développé sous Apex : Geni sutilisés depuis un navigateur internet.

Ce développement a nécessité la création de propriétés particulières

Apex_Doc-Contenant.pdf

Contexte Propriété Commentaire
Fiche chantier  CH_CNT O /  N : permet d'afficher le chantier dans les listes de choix des écrans créés sous Apex pour l'usine.
Peut être interprété comme un chantier en cours.
Fiche fournisseur - transporteur TRANS_CNT O /  N : permet d'afficher le transporteur dans les listes de choix des écrans créés sous Apex pour l'usine.
Fiche magasin MAG_CNT O /  N : permet d'afficher le magasin dans les listes de choix des écrans créés sous Apex.
