Problème : 
Comment afficher le sigle Euro : € ?

Solution : 
Utiliser la combinaison de touches Alt Gr + E, ou Alt + Ctrl + E
Attention ! : il est recommandé d'utiliser l'abréviation EUR et non le sigle graphique €.

Problème : 
A chaque ouverture d'un fichier Excel, le programme me demande si je veux rétablir les liaisons.
Comment rechercher une cellule contenant une liaison ?

Solution :
Aller dans Edition > Liaisons, et vérifier le nom du fichier lié, cliquer sur fermer.
Sélectionner toutes les feuilles du classeur, ( cliquer sur les onglets en maintenant la touche Ctrl enfoncée ).
Faire une recherche sur le nom de fichier lié (Edition > Rechercher).
Cas particulier : Aucune cellule ne contient de référence à un fichier externe
Vérifier les données sources des graphiques.
Vérifier les références utilisée dans le menu Insertion > Nom > Définir...

Problème : 
Comment supprimer une liaison.

Solution :
Se positionner sur la cellule utilisant une liaison vers un fichier externe et la supprimer ou la modifier.

Problème : 
J'ai vérifié toutes les feuilles, les noms et les graphiques, je ne trouve aucune référence au fichier lié

Solution :
Ceci provient d'un problème interne au fichier Excel qui a gardé par erreur une référence externe.

  1. Créer un nouveau classeur vide, l'enregistrer.
  2. Se placer dans le fichier d'origine, dans Edition > Liaisons , cliquer sur Modifier la source
  3. Choisir le fichier nouvellement créé.
  4. Sélectionner toutes les feuilles du fichier d'origine, choisir Déplacer ou  copier
  5. Dans la zone de liste déroulante Dans le classeur, choisir le nouveau fichier puis valider par OK.
  6. Les feuilles sélectionnée sont transférées dans le nouveau classeur.
  7. Enregistrer le nouveau classeur.
  8. Vérifier si l'option Liaisons est toujours accessible dans le menu Edition.
  9. Si non, le la liaison erronée n'existe plus, utilisez ce nouveau fichier en remplacement du fichier d'origine.

Problème : 

Sous Excel 2000, lorsque ma feuille est protégée, le filtrage automatique avec menus déroulants est bloqué. Peut-on débloquer ce mode de filtrage sur une feuille protégée ?

Solution :
Pour utiliser le filtre sur une feuille protégée : Dans le module ThisWorkbook :

Private sub Workbook_Open()
 Feuil1.EnableAutoFilter = True

 Feuil1.Protect Contents:=True, UserInterfaceOnly:=True
 end sub

Outlook

Pour ajouter sa signature automatiquement à la fin de chaque e-mail

Avec Outlook 2000

Aller dans Outils > Options
Aller dans l'onglet Format du Courrier
Cliquer sur Sélecteur de signature
Cliquer sur Nouveau
Choisir Démarrer avec un exemplaire vide cliquer sur Suivant >
Une nouvelle boite de dialogue apparait, taper le texte qui servira de signature
Enregistrer votre texte en cliquant sur Terminer
Cliquer sur OK dans les boites de dialogue précédentes pour valider votre sélection
Dans l'onglet d'origine Format du Courrier, choisir votre signature dans la boite de liste déroulante
Valider votre sélection par OK

Note : il est possible de préparer une signature sous Word, enregistrer la ficher au format RTF.

Au lieu de choisir Démarrer avec un exemplaire vide , choisir Utiliser ce fichier comme modèle

Fin du tips, votre signature apparaîtra à la fin de chaque nouveau message...

Démarrage automatique d'Outlook à la mise sous tension de l'ordinateur

  1. Cliquez sur le bouton Démarrer de Windows, pointez sur Paramètres, puis cliquez sur Barre des tâches.
    Dans Microsoft Windows 98, cliquez sur Barre des tâches et menu Démarrer.
    Cliquez sur l'onglet Programmes du menu Démarrer, puis sur Ajouter.
  2. Cliquez sur Parcourir.
  3. Dans la zone Explorer, cliquez sur le lecteur où est installé Microsoft Outlook.
  4. Dans la liste des dossiers, double-cliquez sur le dossier contenant Outlook.
  5. Double-cliquez sur Outlook, puis cliquez sur Suivant.
  6. Dans la liste des dossiers, cliquez sur Démarrage, puis cliquez sur Suivant.
  7. Dans la zone Sélectionnez le dossier où placer le raccourci, tapez le nom que vous voulez attribuer à ce raccourci (par exemple Microsoft Outlook) puis cliquez sur Terminer.
