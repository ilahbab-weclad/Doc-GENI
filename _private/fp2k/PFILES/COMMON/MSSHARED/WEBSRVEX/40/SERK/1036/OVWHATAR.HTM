 1 sur 6   Description des
               extensions serveur FrontPage

Les extensions serveur de Microsoft® FrontPage® 2000 sont un ensemble de programmes qui s'exécutent sur un serveur Web et prennent en charge l'administration, la création et la navigation sur un site Web FrontPage étendu.

Les extensions serveur FrontPage utilisent l'interface CGI (Common Gateway Interface) ou ISAPI (Internet Server Application Programming Interface), les mécanismes d'extension de serveur Web quasi universels. Elles fonctionnent avec tout serveur Web standard, y compris avec les serveurs Web commerciaux de Microsoft, Netscape, Stronghold et O'Reilly and Associates, et avec les serveurs de freeware et de shareware comme Apache et NCSA. Les extensions serveur sont portables facilement sur les principales plates-formes matérielles et logicielles du marché, pour une compatibilité Web/serveur inter plates-formes.

La communication entre un ordinateur client et un serveur Web contenant les extensions serveur fait appel au protocole HTTP ouvert qu'utilisent les navigateurs Web d'un ordinateur client pour interagir avec un serveur Web. Aucun accès en partage de fichiers n'est requis sur le serveur Web, ni un accès FTP ou Telnet. Aucun appel de partage du système de fichiers propriétaire n'est nécessaire pour utiliser les extensions serveur FrontPage.

Quand les extensions serveur FrontPage sont installées sur un serveur Web, les fonctionnalités d'administration et d'opérations d'auteur de site Web FrontPage étendu sont accessibles depuis tout ordinateur doté du client FrontPage, qu'il soit sur Internet ou fasse partie d'un intranet. Les fonctionnalités de navigation des extensions serveur sont disponibles à partir de tout navigateur Web.

Les extensions serveur FrontPage vous permettent d'effectuer les opérations suivantes :

  • Administrer des sites Web FrontPage étendus

    Vous pouvez définir des autorisations pour les auteurs, les administrateurs et les visiteurs de site Web. Le programme des extensions serveur FrontPage qui prend en charge l'administration des sites Web FrontPage étendus s'appelle admin.exe sur les systèmes UNIX et admin.dll sur les systèmes Microsoft® Windows NT®.

  • Créer des sites Web FrontPage étendus

    Vous pouvez gérer automatiquement les liens hypertexte, générer et gérer les barres de navigation sur toutes les pages, et mettre en forme les pages automatiquement pour leur donner une apparence soignée. Le programme des extensions serveur FrontPage qui prend en charge la création de sites Web FrontPage étendus s'appelle author.exe sur les systèmes UNIX et author.dll sur les systèmes Windows NT.

  • Ajouter des fonctionnalités à votre site Web.

    Vous pouvez ajouter des groupes de discussion interactifs, des compteurs d'accès et des formulaires de recherche. Le programme des extensions serveur FrontPage qui prend en charge les fonctionnalités de navigation sur les sites Web FrontPage étendus s'appelle shtml.exe sur les systèmes UNIX et shtml.dll sur les systèmes Windows NT.

 

La conception des extensions serveur FrontPage et du client FrontPage limite les coûteux transferts de fichiers sur Internet. Quand un auteur utilisant FrontPage ouvre un site Web FrontPage étendu à partir d'un serveur Web où les extensions serveur sont installées, des informations sur le site Web, comme sa carte des liens hypertexte, sont téléchargées sur la machine cliente pour que FrontPage puisse les afficher. Toutefois, les pages et les autres fichiers qui constituent le site Web FrontPage étendu restent sur le serveur Web.

Dans FrontPage, une page n'est téléchargée via Internet que lorsqu'elle est ouverte dans FrontPage ou dans un autre application Microsoft Office pour y être modifiée. Ce mécanisme est très efficace : il est possible de modifier un site Web entier directement sur un serveur Web pour le coût du téléchargement et de la modification d'un seul fichier. Par exemple, le composant Insertion de page de FrontPage peut servir à insérer l'adresse et le numéro de téléphone d'une société dans le pied de page de toutes les pages du site Web de la société. Si le numéro de téléphone change, il suffit de télécharger et d'ouvrir la page contenant l'adresse et le numéro de téléphone avec le client FrontPage. Une fois ce numéro mis à jour et la page enregistrée, les extensions serveur FrontPage réinsèrent le numéro sur toutes les autres pages sur le serveur Web.

Sur les serveurs Web exploitant Microsoft® Windows®, les extensions serveur sont intégrées au système de contrôle de version Microsoft® Visual SourceSafe™, qui permet d'archiver et d'extraire des fichiers sur le serveur Web. Les extensions serveur prennent aussi en charge des opérations d'archivage et d'extraction « allégées » qui ne nécessitent pas Microsoft Visual SourceSafe mais empêchent les auteurs d'écraser des fichiers actuellement utilisés par un autre auteur.

Avec FrontPage, toutes les applications Microsoft Office utilisent les extensions serveur pour ouvrir et enregistrer les fichiers stockés sur les sites Web FrontPage étendus. Il en va de même pour Microsoft® Visual InterDev™.
