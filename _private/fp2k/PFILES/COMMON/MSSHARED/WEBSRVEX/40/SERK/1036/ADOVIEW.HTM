Kit de ressources des extensions serveur  Microsoft FrontPage 2000

Outils et techniques d'administration

Les extensions serveur Microsoft® FrontPage® sont fournies avec des outils permettant de les administrer :

  • L'utilitaire Fpsrvadm est une application conçue pour les systèmes d'exploitation UNIX et Microsoft® Windows NT®. Il offre une gamme complète d'opérations pour les extensions serveur FrontPage. Utilisez Fpsrvadm à partir de la ligne de commande ou de fichiers de commandes. Fpsrvadm doit être exécuté sur l'ordinateur serveur.
  • Le composant logiciel Microsoft Management Console (MMC) pour extensions serveur FrontPage administre ces dernières sous Windows NT version 4.0 ou ultérieure. Les composants logiciels MMC fournissent une interface graphique pour l'administration des ordinateurs et des programmes. Le composant logiciel MMC pour extensions serveur FrontPage permet d'administrer les extensions serveur sur un serveur Web fonctionnant sous Windows NT.
  • L'utilitaire Fpremadm permet d'administrer les extensions serveur FrontPage à partir d'un PC Microsoft® Windows® qui n'est pas l'ordinateur sur lequel le serveur Web fonctionne. Son interface est basée sur l'utilitaire Fpsrvadm et permet d'effectuer toutes les commandes de Fpsrvadm. Utilisez Fpremadm pour administrer à distance les extensions serveur FrontPage sur un PC Windows à partir de la ligne de commande ou d'un fichier de commandes.
  • Les formulaires d'administration HTML pour extensions serveur FrontPage sont des pages HTML permettant d'installer et d'administrer à distance les extensions serveur FrontPage à partir d'un navigateur Web sur n'importe quel ordinateur connecté à Internet. Ces formulaires sont copiés sur le disque dur de votre serveur Web pendant l'installation des extensions serveur FrontPage. Utilisez-les pour administrer à distance les extensions serveur FrontPage avec un navigateur Web à partir d'un ordinateur quelconque connecté à Internet.

HAUT

Installer

Pour qu'un auteur puisse utiliser le programme client FrontPage dans le but de créer un site Web sur un serveur virtuel, vous devez installer les extensions serveur FrontPage sur ce serveur virtuel. (Vous remarquerez qu'il s'agit là d'une opération distincte de l'installation des extensions serveur sur votre machine serveur avec la routine d'installation des extensions serveur FrontPage.) Une fois les extensions serveur installées, les auteurs et les administrateurs qui disposent des autorisations adéquates peuvent utiliser toutes les fonctions du client FrontPage.

L'installation des extensions serveur FrontPage sur un serveur virtuel crée un site Web racine FrontPage étendu sur le serveur virtuel. L'installation des extensions serveur sur un serveur virtuel ajoute également certains fichiers et dossiers au serveur virtuel. Voir Répertoires FrontPage spéciaux et emplacements de stockage pour plus d'informations à ce sujet.

Vous pouvez installer les extensions serveur FrontPage sur un serveur virtuel avec :

  • le composant logiciel MMC FrontPage,
  • l'utilitaire Fpsrvadm,
  • les formulaires d'administration HTML,
  • l'utilitaire Fpremadm.
HAUT

Mettre à niveau

Une fois les extensions serveur FrontPage installées sur un serveur virtuel, vous pouvez les mettre à niveau avec une version plus récente. Les extensions serveur sont mises à niveau sur le site Web racine d'un serveur virtuel et sur les éventuels sous-sites de ce serveur virtuel.

Vous pouvez effectuer la mise à niveau des extensions serveur FrontPage sur le serveur virtuel avec :

  • le composant logiciel enfichable MMC FrontPage,
  • l'utilitaire Fpsrvadm,
  • les formulaires d'administration HTML,
  • l'utilitaire Fpremadm.
HAUT

Désinstaller

Vous pouvez désinstaller les extensions serveur FrontPage sur un serveur virtuel. Cette opération désinstalle également les extensions serveur des sous-sites du site racine. La désinstallation n'efface pas le contenu du site Web.

Cette opération laisse suffisamment de méta-informations dans la zone de contenu de chaque site Web pour ramener chaque site à son état antérieur lorsque les extensions serveur sont réinstallées. À titre d'exemple, les sous-sites présents lors de la désinstallation des extensions serveur sont restaurés. Vous pouvez utiliser Full Uninstall pour désinstaller totalement les extensions serveur sur un serveur virtuel.

Vous pouvez désinstaller les extensions serveur FrontPage sur un serveur virtuel avec :

  • le composant logiciel enfichable MMC FrontPage,
  • l'utilitaire Fpsrvadm,
  • les formulaires d'administration HTML,
  • l'utilitaire Fpremadm.
HAUT

Désinstaller complètement

Cette opération désinstalle les extensions serveur FrontPage sur le port et le serveur virtuel spécifiés. Si le site Web racine comporte des sous-sites, les extensions sont également désinstallées sur les sous-sites. Contrairement à Uninstall, Full uninstall ne laisse aucune information générée par FrontPage dans la zone de contenu du site Web.

Vous pouvez désinstaller totalement les extensions serveur de FrontPage sur un serveur virtuel avec :

  • le composant logiciel enfichable MMC FrontPage,
  • l'utilitaire Fpsrvadm,
  • les formulaires d'administration HTML,
  • l'utilitaire Fpremadm.

Changer le propriétaire

Sous UNIX seulement, vous pouvez spécifier que les extensions serveur FrontPage changent le propriétaire des répertoires créés par FrontPage et par les programmes de remplacement des extensions serveur en même temps que le contenu du site Web, et affecter aux programmes de remplacement des extensions serveur la valeur SUID. Utilisez cette opération pour renforcer la sécurité.

Vous pouvez changer le propriétaire des extensions serveur FrontPage et du contenu du site avec :

  • l'utilitaire Fpsrvadm,
  • l'utilitaire Fpremadm.

Recalculer un site Web

Bien qu'en général cela ne soit pas nécessaire, vous pouvez synchroniser des bases de données de contenu FrontPage avec l'état actuel d'un site. Cette opération recalcule et répare tous les liens hypertexte internes d'un site FrontPage étendu. Elle réintègre les pages des composants Insertion de pages, recalcule d'autres composants FrontPage (comme les formulaires de recherche et les barres de navigation), réapplique les bordures à toutes les pages qui en utilisent, redéfinit les autorisations dans les pages de résultats du programme de traitement des formulaires et recalcule les index de texte.

Vous pouvez recalculer un site FrontPage étendu avec :

  • le composant logiciel enfichable MMC FrontPage,
  • l'utilitaire Fpsrvadm,
  • les formulaires d'administration HTML,
  • l'utilitaire Fpremadm.

HAUT

Activer le contrôle de source

Les extensions serveur FrontPage offrent un contrôle de source intégré et le contrôle de source Microsoft® Visual SourceSafe™ (VSS). Elles fonctionnent avec une version 5.0 ou ultérieure de Visual SourceSafe. Lorsque l'une ou l'autre méthode de contrôle de source est activée, les auteurs peuvent utiliser des commandes FrontPage pour contrôler les pages et autres fichiers à l'intérieur et à l'extérieur d'un site Web FrontPage étendu. Lorsque le contrôle Visual SourceSafe est activé, les auteurs bénéficient de fonctionnalités avancées comme le suivi et la journalisation des modifications de chaque fichier, la consultation de l'historique d'un fichier et le retour à des versions antérieures d'un fichier.

  • Configuration de comptes d'utilisateur pour une utilisation au sein de projets Visual SourceSafe
  • Synchronisation d'un site FrontPage étendu avec un projet Visual SourceSafe
  • Activation du contrôle de source intégré sous Windows
