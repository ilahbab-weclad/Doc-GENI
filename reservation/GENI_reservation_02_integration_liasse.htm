Intégration Liasse - FAQ
Rappel pour les utilisateurs occasionnels la consultation des stocks se fait sur : Site = SP-PINON - Magasin = MG-PINON-00
Dans les zones de couleur bleu ou grisé, vous pouvez faire apparaître une liste de choix en appuyant sur F4.
Dans toutes les listes, il est possible de créer un filtre (une requête) avec les raccourcis F2 Shift+F2

Cet écran permet de récupérer les informations en provenance du logiciel de saisie graphique.

Importer une nouvelle liasse :

  1. Se placer dans Nom liasse, appuyer sur F4 pour rechercher le fichier de saisie graphique ( *.LIS ) 
  2. Cliquer sur Lire liasse
    Le logiciel lit le fichier en provenance de la saisie graphique et importe les informations contenues.
  3. Cliquer sur Contrôle liasse. Le logiciel lit les informations provenant de la saisie graphique, alimente une table temporaire et vérifie l'existence de tous les articles génériques. En fin de contrôle le logiciel ouvre un fichier Excel indiquant les articles génériques inconnus à créer. 
    Note : Aucun article n’est créé.
  4. Le pavé Table, permet de consulter à l'écran les différentes informations transférées table par table.
  5. Cliquer sur Erreur Nomenclature, la liste doit être vide.
  6. Cliquer sur Ref. GP inconnues, la liste doit être vide.
  7. Si aucune erreur n'est sgnalée, cliquer sur Editer liasse pour vérification par le service concerné.

Note : Si des articles inconnus ont été détectés, les créés puis relancer le contrôle de la liasse.

Origines probables des erreurs d'intégration de liasse
  • L'article générique n'existe pas
  • La composition n'existe pas.
  • La composition est mal orthographiée. exemple :0 à la place de O
  • Dans le cas de tôle ou de profilé, si la teinte n'est pas définie.
Il est possible de vérifier l'intégration en parcourant la liste des tables 

Editer ou ré-éditer une liasse :

  1. Saisir le n° SG, valider par Entrée
  2. Le pavé Table, permet de consulter à l'écran les différentes informations transférées table par table.
  3. Cliquer sur Editer liasse.

Il est possible de sortir différentes éditions :

  • La liasse complète
  • Une partie de la liasse
    Dans ce cas, le logiciel vous demande à partir de quel nœud éditer la liasse.
  • Les références GP inconnues

Editer liasse

 Permet d'éditer la liasse ( liste des composants définis par la saisie graphique et importés dans la GPAO.

Ref. GP Inconnues

 Permet d'éditer la liste des articles non connus par la GPAO.

 Permet d'éditer une partie de la liasse, édition à partir d'un noeud.
