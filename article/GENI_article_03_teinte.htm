Rappel pour les utilisateurs occasionnels la consultation des stocks se fait sur : Site = SP-PINON - Magasin = MG-PINON-00
Dans les zones de couleur bleu ou grisé, vous pouvez faire apparaître une liste de choix en appuyant sur F4.
Dans toutes les listes, il est possible de créer un filtre (une requête) avec les raccourcis F2 Shift+F2

Ce module permet soit de consulter les teintes existantes soit de créer une nouvelle teinte.

Pour une consultation, utiliser la touche F2 et lancer une requête.

Pour créer une nouvelle teinte :

  1. Choisir dans le menu Edition > Insérer un enregistrement ( F7 ),

  2. une nouvelle ligne vierge apparaît,

  3. renseigner les différents champs

  4. valider les changements en appuyant sur F5.

 
Par convention nous avons choisi de codifier la teinte BRUT : 00

Les bicolores sont codifiés : BIC...

Une teinte "mat" correspond habituellement à 30% de brillance

Les anodisés commencent par TN

ex : 
TN15   anodisé 15 microns

TN15BS anodisé 15 microns British Standard ( norme spécifique pour le Royaume-Uni )

Les teintes RAL sont découpées en familles

Numéro de teinte commençant par

  • 1000 : les jaunes

  • 2000 : les oranges

  • 3000 : les rouges

  • 4000 : les roses violets

  • 5000 : les bleus

  • 6000 : les verts

  • 7000 : les gris

  • 8000 : les bruns

  • 9000 : les noirs et les blancs
