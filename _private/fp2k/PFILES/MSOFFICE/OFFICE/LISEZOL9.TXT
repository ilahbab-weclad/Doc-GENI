INSTALLATION DE MICROSOFT OUTLOOK 2000


Désactivation de la protection antivirus avant d'exécuter 
le programme d'installation
---------------------------------------------------------
Certains programmes de protection antivirus, tels
que VSafe.com et Norton AntiVirus AutoProtect, peuvent 
interférer avec le programme d'installation Microsoft 
Outlook 2000. Si vous utilisez un programme antivirus sur 
votre ordinateur, désactivez-le avant d'exécuter l'installation. 
(N'oubliez pas de réactiver ce programme lorsque l'installation 
sera terminée.)


L'utilisation de signes de ponctuation dans les noms de 
dossier lors de l'installation peut causer des problèmes.
---------------------------------------------------------
N'utilisez pas de virgule (,), de guillemet simple (') ou 
de point d'exclamation (!) dans le nom du dossier dans 
lequel vous installez Microsoft Outlook 2000. Il vous est 
conseillé d'utiliser le dossier par défaut ou d'employer 
uniquement des lettres et des nombres.


Configuration minimale requise pour Microsoft Outlook 2000
----------------------------------------------------------
Pour utiliser Microsoft Outlook 2000, il vous faut les 
éléments suivants :

* PC équipé d'un processeur Pentium 75 MHz ou supérieur
* Système d'exploitation Microsoft Windows 95 ou version ultérieure, 
  ou Microsoft Windows NT Workstation 4.0 Service Pack 3 ou 
  version ultérieure
* Windows 95 ou Windows 98 :
  - 16 Mo de mémoire vive (RAM) pour le système d'exploitation, plus 
    8 Mo pour Microsoft Outlook
* Microsoft Windows NT Workstation version 4.0 Service Pack 3 ou 
  version ultérieure :
  - 32 Mo de mémoire vive (RAM) pour le système d'exploitation, plus 
    8 Mo pour Microsoft Outlook
* Microsoft Windows NT Server version 4.0 Service Pack 3 ou 
  version ultérieure :
  - 64 Mo de mémoire vive (RAM) pour le système d'exploitation, plus 
    8 Mo pour Microsoft Outlook

* Espace disque disponible (le chiffre correspond à une 
  installation par défaut. L'utilisation du disque dur dépendra 
  de la configuration choisie. Les options activées pendant 
  l'installation personnalisée peuvent exiger plus ou moins d'espace 
  disque disponible):
  - Installation par défaut : 165 Mo

* Lecteur de CD-ROM
* Moniteur VGA ou de résolution supérieure ; Super VGA recommandée
* Souris Microsoft, Microsoft Intellimouse ou dispositif de
  pointage compatible

Pour utiliser certaines fonctionnalités, vous devez disposer des
éléments ou des services suivants :
* Modem 9600 bauds (14 400 bauds ou plus recommandé)
* Ordinateur multimédia pour bénéficier du son et d'autres 
  effets multimédias
* Microsoft Mail, Microsoft Exchange, Internet SMTP/POP, 
  IMAP4 ou autre logiciel de messagerie compatible MAPI requis 
  pour l'utilisation de la messagerie électronique
* Microsoft Exchange Server requis pour certaines fonctionnalités 
  de groupe de travail avancées dans Outlook
* L'utilisation de certaines fonctionnalités Internet peut nécessiter 
  un accès à Internet et la souscription d'un abonnement séparé auprès 
  d'un fournisseur de services.


Redémarrage obligatoire de Microsoft Outlook pour terminer 
l'installation
----------------------------------------------------------
L'installation de Microsoft Outlook ne s'achève qu'avec le  
redémarrage d'Outlook. Évitez d'installer des compléments, de
modifier les options de prise en charge du courrier, d'envoyer 
du courrier à partir d'autres programmes ou de modifier les 
paramètres de Courrier/Télécopies dans le Panneau de 
configuration avant d'avoir redémarré Outlook.


Un message demandant le code CD Key s'affiche lorsqu'Outlook 
2000 est installé à partir d'une installation administrative.
-------------------------------------------------------------
Lorsque vous installez Outlook 2000 sur votre ordinateur à 
partir d'une installation administrative sur un serveur, 
un code CD Key peut vous être demandé. Cela peut arriver si
l'administrateur système qui a créé l'installation 
administrative n'a pas entré de code CD Key.

Pour résoudre ce problème, demandez à l'administrateur
système de créer une nouvelle installation administrative 
et d'entrer le code CD Key dans la première boîte de 
dialogue. Vous ne serez ainsi plus invité à fournir le 
code CD Key lorsque vous installerez Office 2000 à partir 
de cette nouvelle installation administrative.


Message inattendu au cours de l'installation
--------------------------------------------
Si un message inattendu s'affiche lors de l'installation 
d'Outlook et qu'il apparaît de nouveau lorsque vous essayez 
de réinstaller Outlook, vous pouvez créer un fichier journal 
qui aidera les Services de Support Technique de Microsoft à 
résoudre le problème. Après avoir créé le fichier, contactez 
les Services de Support Technique de Microsoft.

>>>Pour créer le fichier journal :

1. Cliquez sur le bouton Démarrer de la barre des tâches, puis sur 
   Exécuter.
2. Dans la zone Ouvrir, tapez : 

   <CHEMIN>\SETUP.EXE /L*V C:\VERBOSELOG.TXT

   où <CHEMIN> correspond à l'emplacement de Setup.exe. Par  
   exemple, si vous procédez à une installation à partir d'un 
   lecteur de CD-ROM, le texte que vous devez taper doit être 
   semblable à ce qui suit  :

   D:\SETUP.EXE /L*V C:\VERBOSELOG.TXT

3. Cliquez sur OK.

   Le programme d'installation redémarrera et un fichier journal 
   intitulé Verboselog.txt sera créé à la racine de votre 
   lecteur C:.


Installation de Microsoft Outlook 2000 sans supprimer la version 
bêta 2 d'Office 2000 
----------------------------------------------------------------
Lors du démarrage de Microsoft Outlook, il se peut que le message 
suivant s'affiche :

Informations requises manquantes dans le registre. 
Impossible d'exécuter cette application. Réexécutez 
le programme d'installation pour résoudre ce problème.

Il peut également arriver que le programme se ferme après 
quelques secondes.
 
Vous pouvez rencontrer l'un ou l'autre des problèmes  
mentionnés ci-dessus si vous avez installé Outlook 2000 
sans avoir supprimé la version bêta 2 (2221b)  
d'Office 2000.

>>>Pour supprimer la version bêta 2 d'Office 2000 :

1. Cliquez sur le bouton Démarrer dans la barre des tâches,
   pointez sur Paramètres et cliquez sur Panneau de 
   configuration.
2. Double-cliquez sur l'icône Ajout/Suppression de programmes.
3. Dans la liste des programmes installés, cliquez sur Microsoft 
   Office 2000 Premium (qui correspond à la version 
   bêta 2 d'Office 2000).
4. Cliquez sur Ajouter/Supprimer.
5. Cliquez sur Supprimer Office.
6. Cliquez sur Oui lorsqu'un message vous invite à confirmer 
   la suppression. 


Le raccourci Outlook 2000 dans le menu Programmes varie 
selon votre système d'exploitation 
-------------------------------------------------------
Le raccourci Outlook 2000 dans le menu Programmes peut 
présenter les problèmes suivants :

1. Ce problème survient, car votre système d'exploitation
   ne prend pas en charge les raccourcis de Windows Installer.
   Voici les versions de Microsoft Windows qui prennent en
   charge ces raccourcis : 

   * Windows 98
   * Windows 95 ou Microsoft Windows NT version 4 avec 
     Internet Explorer 4.01 Service Pack 1 et Active Desktop 
     installés. 

   Remarque : Si vous installez Internet Explorer 5 sur un 
   ordinateur exécutant Windows 95 ou Windows NT version 4 
   sur lequel Internet Explorer 4.01 Service Pack 1 et 
   Active Desktop sont installés, les raccourcis Windows 
   Installer seront pris en charge.
 
2. Il n'installe pas le programme lors de la première utilisation. 

   Ce problème survient lorsque l'option Installé lors de la première 
   utilisation de la boîte de dialogue Sélection des composants ne 
   s'applique pas à Outlook au moment de l'installation. Cette option 
   n'est pas disponible, car votre système d'exploitation ne prend pas 
   en charge les raccourcis Windows Installer. Ces derniers sont pris en 
   charge par les systèmes d'exploitation indiqués à l'étape 1. 

3. Il n'affiche aucun chemin d'accès sous l'onglet Raccourci de 
   la boîte de dialogue Propriétés du raccourci. 

   Ce problème survient lorsque le raccourci est un raccourci 
   Windows Installer. Les raccourcis Windows Installer ne font 
   pas directement référence au chemin d'accès de la cible du 
   raccourci. Ils contiennent un indicateur que Windows Installer 
   traduit par le chemin d'accès de la cible du raccourci. Les 
   raccourcis Windows Installer sont pris en charge par les 
   systèmes d'exploitation indiqués à l'étape 1.


Prise en charge de l'euro
-------------------------
Windows 98 contient des fonctions qui permettent de taper et
d'afficher le symbole de l'euro. Si vous utilisez Microsoft 
Windows 95 ou Microsoft Windows NT Workstation version 4.0 
Service Pack 3 ou une version antérieure, il vous faudra peut-être 
mettre à jour votre système de façon à y intégrer les fonctionnalités 
permettant d'entrer et d'afficher le symbole de l'euro. Pour 
effectuer cette mise à jour, visitez les sites Web aux adresses 
suivantes :

* Windows 95
http://www.microsoft.com/france/euro/correctifs
/info.asp?mar=/france/euro/correctifs/win95fr.html

* Windows NT 4.0
http://www.microsoft.com/france/euro/correctifs
/info.asp?mar=/france/euro/correctifs/nt4.html


Version de langue d'Office 2000 associée à Small Business 
Server 4.5 en anglais
---------------------------------------------------------
Si vous avez besoin d'une version de langue d'Office 2000 qui puisse 
être associée à Small Business Server 4.5 en anglais, vous devez 
désinstaller toute version anglaise d'Office 2000 et/ou 
d'Outlook 2000 pour garantir une exécution optimale de votre système.

UTILISATION DE MICROSOFT OUTLOOK 2000


Le programme qui a permis de créer le fichier doit être installé 
pour importer des fichiers NetManage ECCO Pro ou Lotus Organizer. 
-----------------------------------------------------------------
Pour importer un fichier Lotus Organizer 2.1 ou NetManage 
ECCO Pro dans Outlook, le programme ayant permis de créer
le fichier doit être installé sur votre ordinateur. Par
exemple, pour importer un fichier ECCO Pro dans Outlook, 
ECCO Pro doit être installé sur votre ordinateur.


La fonctionnalité Collaboration en ligne de NetMeeting requiert 
Windows NT Version 4.0 Service Pack 4.
---------------------------------------------------------------
Lorsque vous utilisez Outlook 2000 sous Windows NT version 4.0, 
la fonctionnalité Collaboration en ligne, qui intègre NetMeeting
aux applications Office 2000, requiert l'installation de Service
Pack 4 ou ultérieur.


Windows Terminal Server affiche le message « Vous avez appelé 
votre propre ordinateur » lors de l'utilisation de NetMeeting.
--------------------------------------------------------------
Les serveurs d'annuaires de NetMeeting conservent la trace des 
personnes qui s'y connectent à l'aide de l'adresse de courrier 
électronique et de l'adresse IP de chaque utilisateur. Windows 
Terminal Server (WTS) ne possède qu'une seule adresse IP. Quand 
deux utilisateurs tiennent une session active sur le même WTS et 
que l'un d'eux essaie d'organiser une réunion avec l'autre, le 
serveur d'annuaires de NetMeeting affiche alors le message 
« Vous avez appelé votre propre ordinateur ». Si les deux  
utilisateurs lancent une session active sur des WTS différents, 
l'organisateur peut alors se connecter au participant.


L'enregistrement d'un calendrier comme page Web crée un dossier.
----------------------------------------------------------------
Lorsque vous entrez un emplacement pour enregistrer votre 
calendrier comme page Web, un nouveau dossier est défini par 
défaut avec le nom de fichier que vous tapez. Si, par exemple, 
vous enregistrez votre calendrier sous c:\Calendrier\Moncalendrier.htm,
le chemin enregistré indiquera en fait : 
c:\Calendrier\Moncalendrier\Moncalendrier.htm


La désinstallation de Microsoft Outlook 2000 sur un 
ordinateur exécutant Exchange Server empêche le 
redémarrage du service Événements Microsoft Exchange.
-----------------------------------------------------
Si vous installez un client Outlook 2000 sur un ordinateur 
exécutant Exchange Server, puis que vous désinstallez ce 
client, vous devez exécuter la commande regsvr32 sur le fichier 
Esconf.dll. Ce programme se trouve dans le répertoire bin 
d'Exchange Server(généralement, c:\exchsvr\bin).


L'importation de listes de distribution privées à partir 
du bureau de poste DB8 de cc:Mail génère des adresses incorrectes.
------------------------------------------------------------------
Ceci concerne SEULEMENT les utilisateurs du Support de Microsoft 
Outlook pour Lotus cc:Mail. Lors de l'importation de listes de 
distribution privées à partir d'un bureau de poste DB8 de cc:Mail  
dans Outlook, les membres des listes de distribution importées qui 
ne sont pas en même temps membres locaux du bureau de poste sont 
importés avec une adresse incorrecte. Pour obtenir plus de détails, 
voir Base de connaissances Microsoft article 219026.


Le bureau de poste de cc:Mail requiert des fichiers VIM dans  
l'instruction du chemin d'accès.
-------------------------------------------------------------
Si vous voulez utiliser Outlook pour accéder à votre bureau de 
poste cc:Mail, il vous faut d'abord indiquer les fichiers Lotus 
Corporation Vendor Independent Messaging (VIM) et l'utilitaire 
d'exportation de cc:Mail dans le chemin d'accès. Ces fichiers 
doivent être installés avant la création ou l'utilisation d'un 
profil à l'aide du Support Outlook pour Lotus cc:Mail. 

Vous pouvez télécharger les fichiers VIM .dll à partir de 
http://www2.support.lotus.com/ftp/pub/comm/ccmail
/dev_tools/vdlw32.zip. L'utilitaire d'exportation est livré avec
Lotus cc:Mail server. Pour les bureaux de poste D8B, l'utilitaire
d'exportation contient les fichiers Export.exe et Ie.ri. Pour les 
bureaux de poste DB6, l'utilitaire d'exportation contient Export.exe. 
Les fichiers se trouvent généralement dans le répertoire ccadmin, 
qui contient les utilitaires d'administration du bureau de poste.


Les boutons de vote n'apparaissent pas dans les clients d'Outlook 98.
---------------------------------------------------------------------
Lorsque vous envoyez un message très long avec des boutons de vote 
à des destinataires utilisant Outlook 98, les boutons de vote 
n'apparaissent pas. Pour y remédier, ramenez la taille du message 
à moins de 50 Ko.  Pour ce faire, utilisez du texte brut comme 
format de message et supprimez toutes les pièces jointes.


Impossible d'importer des certificats à haut niveau de cryptage.
----------------------------------------------------------------
Lorsque vous importez des fichiers PFX 128 bits à haut niveau de 
cryptage, vous risquez d'obtenir le message : « Une erreur s'est  
produite. Impossible d'importer les certificats ». Pour importer 
des certificats à haut niveau de cryptage, effectuez la mise à 
niveau suivante :

* Si vous utilisez Windows 95 ou 98, installez Internet 
  Explorer 5 ou version ultérieure.
* Si vous utilisez Windows NT version 4.0 Service pack 3, 
  installez le Service Pack 4.


Les entrées des listes de distribution du carnet d'adresses 
personnel de Microsoft Exchange ne sont pas importées dans les 
listes de distribution des contacts de Microsoft Outlook.
--------------------------------------------------------------
Lorsque vous créez une liste de distribution de contacts Outlook 
dans un dossier de contacts qui se trouve sur le serveur Exchange, 
vous êtes limité à 130 contacts environ dans la liste de distribution.

>>>Pour contourner cette limite :

1. N'importez pas votre carnet d'adresses personnel si vous y êtes 
   invité la première fois que vous exécutez Outlook 2000.
2. Ouvrez votre carnet d'adresses personnel et convertissez la  
   longue liste de distribution en deux ou plusieurs petites listes 
   de distribution.
3. Importez le carnet d'adresses personnel à l'aide de la commande 
   Importer et Exporter du menu Fichier.


Il se peut que les couleurs ne s'affichent pas correctement sur 
les moniteurs 256 couleurs
---------------------------------------------------------------
Après avoir affiché les fenêtres contextuelles dans les 
rubriques d'aide, il se peut que les couleurs associées à 
certains éléments ne s'affichent pas correctement sur les 
moniteurs 256 couleurs. Par exemple, les éléments suivants 
peuvent apparaître différemment à l'écran une fois que vous 
avez visualisé des fenêtres contextuelles :

* Images bitmaps
* Images incorporées dans les fichiers
* Compagnon Office 
* Liens hypertexte

Pour résoudre le problème d'affichage, changez la palette 
de couleurs de votre moniteur.

>>>Pour changer la palette de couleurs :

1. Cliquez sur Démarrer dans la barre des tâches Windows,
   pointez sur Paramètres, puis cliquez sur Panneau de
   configuration.

2. Double-cliquez sur l'icône Affichage.

3. Sous l'onglet Paramètres, sélectionnez une option  
   autre que 256 couleurs. Microsoft vous recommande de 
   sélectionner une option proposant plus de 256 couleurs, 
   si cette option est disponible.

Outlook met automatiquement à niveau le programme de télécopie

--------------------------------------------------------------
La rubrique d'aide « Utilisation du programme de télécopie

----------------------------------------------------------
Les outils de vérification Microsoft Office 2000 sont regroupés

agréé. Les numéros de référence répertoriés dans l'aide sont

Office 2000, visitez le site Web à l'adresse suivante : 
France : http://www.microsoft.com/france/office/ 
Canada : http://www.microsoft.com/canada/french/office

devraient en fait renvoyer plutôt à la zone Rechercher un contact.

PROBLÈMES RELATIFS À MICROSOFT WINDOWS CE


La modification des configurations de la messagerie électronique 
lorsque Windows CE est connecté génère des problèmes.
----------------------------------------------------------------
Si les Services Windows CE s'exécute lorsque vous essayez de 
modifier les configurations du service de messagerie électronique, 
par exemple si vous voulez passer de Société/Groupe de travail à 
Internet uniquement, la tentative de modification de la 
configuration échouera.

Il faut désactiver les Services Windows CE (déconnecter le 
périphérique CE) avant de modifier les configurations de la 
messagerie électronique dans Outlook.


La réservation directe des ressources n'est pas prise en charge 
dans les demandes de réunion dans Outlook.
---------------------------------------------------------------
Outlook 2000 autorise la réservation directe de ressources dans 
les demandes de réunion. Lorsque ces demandes de réunion sont 
synchronisées avec le périphérique Windows CE à l'aide des 
Services Windows CE version 2.2 ou antérieure, la ressource peut 
être supprimée dans le champ d'emplacement de la réunion et 
transformée en participant obligatoire. Microsoft prévoit de 
résoudre ce problème dans une prochaine version des Services 
Windows CE. La mise à jour devrait être disponible peu après le 
lancement d'Office 2000 sur le site Web de Windows CE : 
http://www.microsoft.com/france/windowsce/


Les listes de distribution ne sont pas prises en charge dans les 
demandes de réunion dans Outlook.
----------------------------------------------------------------
Outlook 2000 introduit une nouvelle fonction qui permet de 
créer des listes de distribution dans les dossiers de contacts. 
Ces listes de distribution peuvent alors être invitées à une 
réunion dans les demandes de réunion d'Outlook. Les Services 
Windows CE version 2.2 et antérieure ne gèrent pas les listes 
de distribution dans Outlook 2000. Lorsque des demandes de 
réunion contenant des participants qui font partie de listes 
de distribution d'Outlook synchronisées avec un périphérique 
Windows CE utilisant CE Services version 2.2 ou antérieure, la 
liste de distribution risque de disparaître de la demande de 
réunion. Microsoft prévoit de régler ce problème dans une 
prochaine version des Services Windows CE. La mise à jour 
devrait être disponible peu après le lancement d'Office 2000 
sur le site Web de Windows CE à l'adresse suivante : 
http://www.microsoft.com/france/windowsce/

PROBLÈMES MULTILINGUES


Incohérence du format de date entre les différentes versions 
internationales 
------------------------------------------------------------
Comme les formats de date diffèrent selon les pays, le calendrier 
d'Outlook ne peut pas reconnaître avec précision le format de date 
correct pour l'importation et l'exportation des formulaires de 
calendrier d'Outlook entre les pays. Par exemple, il se peut que 
les formulaires provenant de pays qui utilisent le format de 
date AAMMJJ ne soient pas importés correctement dans les versions 
de calendrier d'Outlook utilisant un format de date différent 
(par exemple, MMJJAA).

Tahoma pour les signatures. Votre signature peut ne pas s'afficher 
correctement dans d'autres polices.

Nouvelles propriétés (VBA)
--------------------------
Les nouvelles propriétés qui s'appliquent aux modules de
classe dans des projets autonomes sont les suivantes :

* Propriété Instancing

  Définit une valeur qui spécifie si vous pouvez créer des 
  instances d'une classe publique hors d'un projet et, 
  si c'est le cas, comment elles se comporteront. Non  
  disponible lors de l'exécution.

  Valeurs

  La propriété Instancing a les valeurs suivantes :

  Valeur   Description
  ------   -----------

  1        Private (par défaut). D'autres applications
           n'ont pas accès aux données de la 
           bibliothèque de caractères concernant la
           classe et ne peuvent pas créer d'instances à
           partir de cette dernière. Les objets Private 
           ne doivent être utilisés qu'à l'intérieur de 
           votre composant. La propriété Instancing par 
           défaut varie selon le type de projet. Private
           est l'objet par défaut uniquement pour les 
           modules de classe dans les projets autonomes.

  2        PublicNotCreatable. D'autres applications peuvent
           utiliser les objets de cette classe seulement si 
           votre composant crée les objets en premier. 
           D'autres applications ne peuvent pas utiliser la
           fonction CreateObject ou New operator pour créer
           des objets à partir de la classe.


* Propriété Name

  Renvoie le nom utilisé dans le code pour identifier une classe. 
  En lecture seule lors de l'exécution.

  Syntaxe

  objet.Name

  L'emplacement de l'objet représente l'expression d'un objet 
  qui a la valeur d'une classe.

  Remarques

  La propriété Name d'un objet doit commencer par une 
  lettre et comporter 40 caractères au maximum. 
  Elle peut inclure des nombres et des caractères de 
  soulignement (_), mais pas de signes de ponctuation 
  ou d'espaces. Bien que la valeur de la propriété Name 
  puisse être un mot clé, un nom de propriété ou le nom 
  d'un autre objet, cela peut créer des conflits dans 
  votre code.


Utilisation de la touche F3 pour rechercher l'occurrence 
de texte suivante dans la fenêtre de code
--------------------------------------------------------
Appuyez sur F3 pour trouver l'occurrence suivante 
du texte précédemment recherché dans la fenêtre de 
code, et non sur MAJ+F4 comme indiqué dans la  
documentation.

Versions d'Internet Explorer et édition du code HTML
----------------------------------------------------
La sélection fonctionne différemment dans Microsoft Script
Editor pour les éléments sur site selon la version 
d'Internet Explorer que vous avez installée. Un élément
sur site correspond à tout élément qui dispose d'une hauteur 
ou d'une largeur, tel qu'un BOUTON.  

Avec Internet Explorer 4.01, la sélection des éléments sur 
site fonctionne comme suit :

* Le premier clic sur un élément vous permet de modifier 
  le texte au sein de cet élément.
* Le second clic sur un élément sélectionne l'élément.
* Double-cliquer sur un élément revient à sélectionner le
  texte au sein de cet élément.

Avec Internet Explorer 5.0, la sélection des éléments 
sur site fonctionne comme suit :

* Le premier clic sur un élément sélectionne cet élément.
* Le second clic sur un élément vous permet de modifier 
  le texte au sein de cet élément.
* Double-cliquer sur l'élément affiche le code source de 
  cet élément.

Remarque : La sélection des tableaux dans Internet 
Explorer 5.0 est la même que celle employée dans 
Internet Explorer 4.01.

De plus, Internet Explorer 5.0 préserve mieux les espaces 
blancs qu'Internet Explorer 4.01 lorsque vous passez d'un 
affichage à un autre dans l'éditeur.
