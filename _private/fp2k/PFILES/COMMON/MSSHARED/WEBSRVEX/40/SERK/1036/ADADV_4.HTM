Comparaison entre les moteurs de recherche de FrontPage et Index Server

Les extensions serveur Microsoft® FrontPage® peuvent utiliser deux moteurs de recherche au choix. Par défaut, c'est le moteur de recherche intégré WAIS inclus dans les extensions serveur FrontPage qui est utilisé. Sous IIS, si Index Server (Indexing Services) est installé, FrontPage l'utilise à la place du moteur de recherche WAIS. Le tableau suivant recense les avantages et inconvénients de chaque moteur de recherche :

Avantages

Moteur de recherche intégré WAIS Index Server
  • Intégré aux extensions serveur FrontPage, si bien qu'aucune configuration supplémentaire n'est requise.
  • L'index de texte est immédiatement mis à jour quand une page est enregistrée, de sorte que vous disposez d'un retour immédiat dans les formulaires de recherche quand vous créez ou testez des sites.

 
  • L'index de texte n'est pas automatiquement mis à jour quand une page est enregistrée, d'où un gain de performance.
  • Une large palette d'attributs de page est indexée et affichée dans les pages de résultats de la recherche.
  • Vous avez plus de flexibilité pour définir quel contenu doit être inclus dans l'index de texte.
  • Vous pouvez avoir un index des documents Microsoft Office.

 

Inconvénients

Moteur de recherche intégré WAIS Index Server
  • L'index de texte est mis à jour chaque fois qu'une page est enregistrée, ce qui peut fortement ralentir l'enregistrement des pages.
  • Pour purger les documents supprimés de l'index de texte, le site doit être recalculé avec la commande Recalculer les liens hypertexte.
  • Les documents Microsoft Office ne sont pas indexés.

 
  • Une installation séparée est nécessaire et Index Server fonctionne uniquement avec Microsoft Internet Information Services.
  • Une étape de configuration distincte est obligatoire pour chaque serveur virtuel.
  • Il n'y a pas de mise à jour immédiate de l'index de texte car Index Server utilise un système d'indexation en arrière-plan. Le décalage entre l'enregistrement d'une page et la mise à jour de l'index peut être source de confusion pour les auteurs de sites.
