Rappel pour les utilisateurs occasionnels la consultation des stocks se fait sur : Site = SP-PINON - Magasin = MG-PINON-00
Dans les zones de couleur bleu ou grisé, vous pouvez faire apparaître une liste de choix en appuyant sur F4.
Dans toutes les listes, il est possible de créer un filtre (une requête) avec les raccourcis F2 Shift+F2

Ce module permet soit de consulter les sous-familles existantes soit de créer une nouvelle sous-famille.

Pour une consultation, utiliser la touche F2 et lancer une requête.

Pour créer une nouvelle sous-famille :

  1. Choisir dans le menu Edition > Insérer un enregistrement ( F7 ),

  2. une nouvelle ligne vierge apparaît,

  3. renseigner les différents champs

  4. valider les changements en appuyant sur F5.
