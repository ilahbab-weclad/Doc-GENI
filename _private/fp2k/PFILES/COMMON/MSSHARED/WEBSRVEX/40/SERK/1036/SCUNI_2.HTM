Sécurité sous UNIX

 2 sur 10     Présentation de la sécurité sous UNIX

Dans FrontPage, trois types d'utilisateurs sont définis pour chaque site Web FrontPage étendu : les administrateurs, les auteurs et les visiteurs du site. Les autorisations sont cumulatives : tous les auteurs peuvent le visiter et tous les administrateurs disposent des autorisations de création de site et de visite.

Chaque site (et sous-site) Web FrontPage étendu contient des copies de trois scripts CGI exécutables. Ces scripts sont créés dans des dossiers sous le dossier du niveau supérieur d'un site Web FrontPage étendu : admin.exe pour les outils d'administration, author.exe pour la création de sites Web et shtml.exe pour les composants exécutables pendant la navigation comme les programmes de traitement de formulaires. FrontPage effectue toutes les tâches de création de site et d'administration en envoyant des requêtes HTTP POST à ces scripts.

Les auteurs, administrateurs et visiteurs des sites Web FrontPage étendus sont répertoriés dans le fichier d'accès du serveur Web qui spécifie quels utilisateurs peuvent exécuter (POST) ces scripts :

  • Les utilisateurs pouvant exécuter le script shtml.exe sont des visiteurs.
  • Les utilisateurs pouvant exécuter le script author.exe sont des auteurs.
  • Les utilisateurs pouvant exécuter le script admin.exe sont des administrateurs.

 

Dans FrontPage, la liste des administrateurs, auteurs et visiteurs est définie pour chaque site Web FrontPage étendu. Chaque sous-site Web FrontPage étendu hérite des autorisations (la liste précitée) de son site Web parent ou utilise les siennes. Comme tous les autres programmes CGI, les extensions serveur FrontPage ne peuvent s'exécuter que si elles sont stockées dans des répertoires exécutables.

Les extensions serveur FrontPage sont stockées dans trois répertoires sous la racine de chaque site Web FrontPage étendu :

/racine du site Web FrontPage étendu

      /_vti_bin

            shtml.exe

            /_vti_adm

                  admin.exe

            /_vti_aut

                  author.exe

 

Le fichier de configuration du serveur doit être modifié pour faire de _vti_bin, _vti_adm et _vti_aut des répertoires exécutables. Vous lancez et contrôlez cette opération avec Fpsrvadm, l'utilitaire d'administration de serveur de FrontPage.

Pour réduire l'espace disque total requis pour gérer les sites Web FrontPage étendus, les fichiers exécutables FrontPage stockés dans les répertoires _vti_* sont des amorces de fichiers exécutables. Chacune appelle un fichier exécutable complet installé dans le répertoire /usr/local/frontpage/version4.0/exes.
