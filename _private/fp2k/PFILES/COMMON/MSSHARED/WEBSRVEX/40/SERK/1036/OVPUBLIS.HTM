 5 sur 6   Publication de sites Web
FrontPage étendus

Quand vous publiez un site Web FrontPage étendu, vous permettez aux visiteurs de le parcourir à partir d'un serveur Web sur Internet ou sur un intranet. Internet et les intranets utilisent généralement des méthodes de publication différentes.

Publication sur Internet

Pour la publication sur Internet, l'auteur crée généralement un site Web FrontPage étendu sur l'ordinateur client. Une fois le site terminé et testé, l'auteur le publie sur le serveur Web d'un fournisseur de services Internet en utilisant la commande Publier le site Web sur le client FrontPage. Il est intéressant de créer un site Web sur un système de fichiers ou sur un serveur Web local car cela n'impose pas aux auteurs de se connecter à un fournisseur de services Internet lorsqu'ils travaillent sur un site Web FrontPage étendu.

La commande Publier le site Web copie le site Web FrontPage étendu d'un serveur Web source (ou du système de fichiers d'un ordinateur client) vers un serveur Web de destination en mode batch. Par défaut, seuls les fichiers nouveaux ou modifiés sont copiés. Les pages et les fichiers supprimés du site Web source sont également supprimés du site Web de destination.

Quand un auteur publie un site Web FrontPage étendu avec la commande Publier le site Web, la page d'accueil est renommée, si nécessaire, pour respecter les conventions de dénomination du serveur Web de destination. De plus, tous les composants de FrontPage du site Web FrontPage étendu sont régénérés pour tirer parti des fonctionnalités spécifiques à la plate-forme. Par exemple, quand un site Web FrontPage étendu est publié sur un serveur IIS qui exploite Microsoft Index Server, tous les formulaires de recherche du site Web sont configurés pour utiliser cette application.

Publication sur un intranet

Pour la publication sur un intranet, la méthode la plus courante n'est pas la commande Publier le site Web. L'auteur travaille plutôt directement sur un serveur Web d'un réseau interne qui sert généralement à partager des informations au sein d'une organisation. Chaque fois qu'une page est ouverte à partir de ce serveur Web et modifiée, la modification est publiée sur l'intranet lorsqu'elle est enregistrée dans FrontPage.
