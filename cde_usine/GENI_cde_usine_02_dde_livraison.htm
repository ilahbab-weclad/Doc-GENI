Dans les zones de couleur bleu ou grisé, vous pouvez faire apparaître une liste de choix en appuyant sur F4.
Dans toutes les listes, il est possible de créer un filtre (une requête) avec les raccourcis F2 Shift+F2

Cet écran permet de saisir une demande de livraison (DL).

Une demande de livraison permet 

  • d'éclater une ou plusieurs commandes usine pour un lancement de fabrication (Lancement OF DL)
  • de préparer un Bordereau de Livraison selon un plan de camionnage

Attention ! Les Demandes de Livraisons font obligatoirement suite à une Commande Usine.

Création d'une nouvelle DL :

  1. Laisser vide le champ N° DL (numéro attribué automatiquement).
  2. Saisir les autres champs : Responsable, Expéditeur, Chantier, etc... (cf. identification des zones)
  3. Dans la zone U.M.P., saisir le code d'Unité de Manutention Primaire (code de la palette ou du pupitre manipulé)
  4. Saisir le n° Ordre (numérique), correspondant à l'emplacement de l'article sur l'UMP.
  5. Saisir le numéro de CDE ou faire une recherche par F4
  6. Saisir le code Article commandé ou faire une recherche par F4
    Attention : la recherche se fait par l'abrégé du générique ou le standard, puis sur l'éphémère.
    La liste des articles affichés est limitée aux articles présents dans la commande sélectionnée.
  7. Le programme affiche le numéro de ligne de commande et la quantité commandée.
  8. Valider la saisie par F5.
  9. Editer ou ré-éditer la DL en cliquant sur ( Ctrl + 0 ).

Consultation d'une DL  existante:

  1. Saisir le N° , ou faire une recherche par F4
  2. Valider par Entrée

Identification des zones :

Champ Désignation
N° DL Numéro de demande de livraison (attribué automatiquement à la création)
Date création - par défaut, la date du jour
Responsable Matricule et nom de la personne qui saisi la DL
Expéditeur Code du site expéditeur (Usine de Pinon)
Resp. Exp. Identification de la personne responsable des expéditions du site expéditeur
Chantier Code du chantier concerné par la DL
Agence Code de l'agence responsable du chantier
Livré à Code du site de livraison ( par défaut , code du Chantier)
Resp. Livr. Identification de la personne responsable des réception sur site de livraison
Date attendue Date de réception sur lieu de livraison
A expédier le Date d'expédition = date attendue - délai de transport entre site d'expédition et site de livraison
