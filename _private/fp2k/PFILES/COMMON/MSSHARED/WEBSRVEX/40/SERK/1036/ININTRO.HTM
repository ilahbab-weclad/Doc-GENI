Installation des extensions serveur FrontPage

La procédure d'installation des extensions serveur FrontPage est réalisée en deux temps. Le programme d'installation des extensions serveur copie tout d'abord les extensions dans un répertoire FrontPage unique sur le disque dur de l'hôte. Les versions stub des exécutables des extensions serveur sont ensuite installées sur le site Web racine de chaque serveur virtuel mis en place sur l'hôte et, le cas échéant, sur chaque sous-site Web présent sur le serveur. Vous pouvez préciser, au cours de l'installation, les serveurs virtuels sur lesquels les extensions serveur doivent être installées.

Une fois que les extensions serveur ont été copiées sur le disque dur de l'hôte, elles doivent être ajoutées à chaque nouveau site Web FrontPage avec extensions que vous créez. Sur certaines plates-formes, le programme d'installation du client FrontPage se charge automatiquement de cette opération ; sur d'autres, l'ajout des extensions doit faire l'objet d'une tâche administrative distincte.
