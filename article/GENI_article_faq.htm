Teinte RAL

Le nuancier RAL est principalement utilisé dans le choix des couleurs de peinture dans les domaines du bâtiment, de l’industrie, de la carrosserie ou de la sécurité routière. Le principe étant d’avoir des couleurs codifiées dans un nuancier universel. Le nuancier RAL CLASSIC comporte 200 couleurs codées de la manière suivante : chaque couleur est représentée par un code à quatre chiffres, le premier chiffre représente la teinte et les deux derniers le code de la couleur.

Consultez ce site internet pour avoir les aperçus

nota : ce site propose également les codes RVB - RGB et CMJN - CMYK des teintes.

Brillant:  85 % de brillance +/- 5% 
Satiné:    70 % de brillance +/- 5% 
Mat:       30 % de brillance +/- 5% 
Très mat:  20 % de brillance +/- 5%

Prix Std Matière 

Articles de catégorie SF ou PF :
Les prix sont enregistrés dans les fiches articles.

Articles de catégorie MP :
Ces articles sont liés au Tarif Achat ou Tarif Standard suivant la commande saisie :

  • Tarif Achat = Commandes fournisseur
  • Tarif Standard = Commandes usine

Tarif des profilés bicolores

  1. Renseigner les propriétés de l'article générique :
    • SURF_EXT
    • SURF_INT
  2. Lors de la création de l'article éphémère, ces surfaces seront multipliées par la longueur de l'éphémère
  3. Dans la base tarifs, créer une grille de tarif en utilisant les critères de surface définis précédemment
    Note : Renseigner les bornes avec les noms de la teinte bicolore  

Les propriétés SURF... sont saisies pour 1 m².  cela correspond au périmètre du plan de filière.  
(ex: pour le profl 00-117 : SURF =  95 mm > .0095 m )

Pour une teinte bicolore, il suffit d'utiliser les propriétés SURF_INT et SURF_EXT à la place de SURF_TOT.

 

Qté de nomenclature négative

Certaines quantités de nomenclature sont négatives !!! Pourquoi ?

Pour annuler des pièces ajoutées automatiquement par le logiciel de saisie graphique et les remplacer par des pièces spéciales

 

Comment connaître les cas d'emploi d'un article ?

  • Aller dans la fiche article concernée, (ex. : SPE-RDB-R01)
  • Cliquer sur le bouton pour accéder à la nomenclature


  • Appuyer sur la touche F3
  • Couper le code article dans le champ Composé (Ctrl+x)
  • Coller le code article dans le champ Composant (Ctrl+v)

 

 

Rechercher un article selon le repère agence

Lors de la création d'un article, ilest possible que le code agence ne soit pas repris dans le code article en GPAO
Dans ce cas, le code agence est noté dans la désignation.

  • Aller dans Article > Liste articles
  • Appuyer sur F2 pour faire une requête
  • Dans le champ désignation taper %code_agence%
  • Lancer la requête Shift+F2

Codification des articles

Il est STRICTEMENT interdit de mettre dans un code article les caractères suivants :

  • un espace
  • un ' (simple cote, touche 4 du clavier)

Merci de votre compréhension

Codification d'un profil externe (ex : paralu)

Si le profil se nomme P56, le code Rinaldi sera 0FP56

0 : Lister aves les profils (tous les profils rinaldi commencent dans GENI par un chiffre)

F : Fournisseur

 

Trouver les tôles créées pour un chantier

Aller dans Articles > Liste articles

(Ecran F001_LIS)

Appuyer sur F2 pour commencer une requête

Dans la colonne Article saisir :a

lancer la requête avec SHIFT+F2

Il apparait une boite de dialogue "Query/Where"

saisir dans cette boite : :a like 'T%COV%' order by :a

cliquer sur OK

apparait la liste des tôles existant dans geni, par ordre alphabétique.

T%COV% code article qui commence par T et contient COV (code du chantier)
