Rappel pour les utilisateurs occasionnels la consultation des stocks se fait sur : Site = SP-PINON - Magasin = MG-PINON-00
Dans les zones de couleur bleu ou grisé, vous pouvez faire apparaître une liste de choix en appuyant sur F4.
Dans toutes les listes, il est possible de créer un filtre (une requête) avec les raccourcis F2 Shift+F2

Comment retrouver un code article ?

Via l'écran : Articles > Listes articles
Lance une requête : appui sur la touche : F2 ou l'icône 
Saisie dans la colonne : Article
de tout ou partie du code article recherché.
%POI%93%
note : le signe % remplace les caractères inconnus
Demande du résultat de l'interrogation avec un appui sur les touches : Shift + F2 ou l'icône 
Plus d'info sur les requêtes dans la doc GENI : Requêtes
Ce système de requête peut être utilisé dans n'importe quelle liste affichée dans GENI.
