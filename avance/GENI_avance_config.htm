Dans les zones de couleur bleu ou grisé, vous pouvez faire apparaître une liste de choix en appuyant sur F4.
Dans toutes les listes, il est possible de créer un filtre (une requête) avec les raccourcis F2 Shift+F2

Comment mettre à jour les textes par défaut ?

Se connecter sur Géni Admin
Aller dans le menu  Paramétrage > Config Param

Install GENI

Vérifications suite à installation de GENI:

Un raccourci vers C:\GEP_LOG\RAPATRIER\LOCAL_M6.BAT est présent dans le menu démarrer :

> Programmes > Démarrage

Le raccourci "Cible" placé sur le bureau de windows a dans la ligne le paramètre : MENU=ERP1

Le PATH contient entre autre : ;C:\ORANT\BIN;C:\orant\jdk\bin;C:\GEP_LOG\DLL;

L'arborescence C:\GEP_LOG\GED\Temp existe, si non, créer les dossiers GED et Temp

La DLL OCIW32.DLL situé dans C:\ORANT\BIN date de 2000

Le répertoire C:\GEP_LOG possède les fichiers suivants :

- PLUS80W.EXE

- PLUS80.EXE

Vérifier que l'arborescence suivante existe : C:\GEP_LOG\GED\Temp

 

Redémarrer le poste pour vérifier le bon lancement de LOCAL_M6.BAT (maj des programmes de geni en local)

 

Installation du viewer autocad  : AcmeCad Converter

http://www.dwgtool.com/cadconvert.htm

GENI est paramétré pour trouver ce programme dans C:\Program Files\

Depuis win 7 l'installation des programmes se fait par défaut dans C:\Program Files (x86)\

Il faut, à l'installation,

  • Forcer l'emplacement de l'installation.
  • Au premier démarrage d'AcmeCad, le lancer en tant qu'administrateur.
  • Aller dans le menu Option > Create association

L'installation de GENI doit comporter les chemins ci-dessous:

C:\GEP_LOG\GED\Temp
et 
C:\GEP_LOG\GED\Bibli
qui contient deux fichiers .bat avec les scripts de conversion avec acmecad

GENI_DWGJPG.BAT - (pour création de la miniature en jpg)

REM   %1   Repertoire source du DWG
REM   %2   Nom du Fichier DWG (sans extension)
REM   %3   Repertoire destination du fichier Jpg
REM   répertoire temporaire GED : C:\GEP_LOG\GED\TEMP

REM   /w 145 /h 167 car ds fiche article on a une image de 145x167

COPY %1%2.dwg %3 /Y
"c:\Program Files\Acme CAD Converter\AcmeCadConverter.exe" /r /e /j 10 /f 2 /P 1 /w 145 /h 167 %3\%2.dwg
DEL %3\%2.dwg

GENI_DWGDXF.BAT - (pour création d'une copie au forat dxf)

REM   %1   Repertoire source du DWG
REM   %2   Nom du Fichier DWG (sans extension)
REM   %3   Repertoire destination du fichier dxf
REM   répertoire temporaire GED : C:\GEP_LOG\GED\TEMP

COPY %1%2.dwg %3 /Y
"c:\Program Files\Acme CAD Converter\AcmeCadConverter.exe" /r /x2000 %3/%2.dwg %3\%2.dxf
DEL %3\%2.dwg
