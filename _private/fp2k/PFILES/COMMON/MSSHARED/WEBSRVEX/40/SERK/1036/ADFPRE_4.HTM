Sécurité de l'administration à distance

L'administration à distance rend généralement votre serveur Web plus vulnérable car une communauté plus large d'utilisateurs dispose d'un accès potentiel à la machine serveur Web par l'intermédiaire d'Internet. Avec FrontPage, le risque qu'une personne non autorisée puisse accéder aux sites Web FrontPage étendu sur votre serveur, modifier les paramètres du site, voire supprimer des sites, est accru. Pour éviter ce type de situation, les précautions suivantes sont recommandées :

  • Exiger une connexion sécurisée (telle que SSL) pour communiquer avec Fpadmdll.dll ou Fpadmcgi.exe. Puisque les informations de configuration et — dans certains cas — les noms d'utilisateurs et les mots de passe sont communiqués sur le réseau avec ces méthodes, une connexion sécurisée évite que les mots de passe ne soient lus directement par les pirates du réseau.
  • Fournir un accès à Fpadmdll.dll ou Fpadmcgi.exe par l'intermédiaire du système de sécurité du serveur Web. Exiger qu'un utilisateur se connecte sous un compte d'administrateur sécurisé sur le serveur Web évite les accès non autorisés.
  • Exiger l'utilisation d'un port HTTP non standard pour accéder à Fpadmdll.dll ou Fpadmcgi.exe. Il est alors beaucoup plus difficile pour les pirates du réseau de deviner l'URL des formulaires d'administration HTML ou des programmes d'administration à distance.
  • Utiliser les restrictions de masque d'adresses IP pour empêcher les ordinateurs non autorisés d'accéder aux formulaires d'administration HTML, Fpadmdll.dll ou Fpadmcgi.exe. En général, l'accès est refusé à toutes les adresses IP non associées au propriétaire du serveur FrontPage étendu à administrer.
