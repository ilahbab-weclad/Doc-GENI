Administration à distance

Activation de l'administration à distance sous IIS 3.0

Que vous utilisiez l'utilitaire de ligne de commande pour l'administration à distance Fpremadm ou les formulaires d'administration des extensions serveur HTML pour administrer un serveur IIS 3.0 à distance, vous devez activer les formulaires d'administration HTML selon la méthode décrite dans cette rubrique.

Vous devez exécuter les formulaires d'administration HTML sur un port sécurisé. L'utilisation d'un port sécurisé n'est possible que si un certificat de sécurité est installé sur le serveur. Si vous ne possédez pas un certificat de sécurité avant d'activer les formulaires d'administration HTML, utilisez l'application Gestionnaire de clés pour faire une demande de certificat de sécurité, soumettez la requête à un responsable de clés, puis utilisez l'application Gestionnaire de clés pour installer le certificat renvoyé par le responsable de clés. La documentation IIS contient plus de détails sur ce processus.

Une fois que vous disposez d'un certificat de sécurité, les étapes suivantes activent les formulaires d'administration HTML pour une utilisation à distance avec une sécurité optimale.

  1. Déterminez quel compte (ou groupe de comptes) de la machine Windows NT aura accès aux formulaires d'administration HTML.

    Ce compte doit être membre du groupe des administrateurs de la machine. Si nécessaire, créez un nouveau compte avec le Gestionnaire des utilisateurs Windows NT. Selon la configuration du compte de la machine, fournir un accès au groupe des administrateurs peut être une meilleure solution que donner accès à plusieurs comptes individuels de la machine.

  2. Ouvrez Windows Explorer à l'emplacement des formulaires d'administration HTML sur le disque dur, par défaut C:\Program Files\Common Files\Microsoft Shared\Web Server Extensions\40\. Sélectionnez le dossier Admisapi, cliquez sur Propriétés dans le menu Fichier, puis sur Autorisations dans l'onglet Sécurité.
  3. Dans la boîte de dialogue Autorisations du répertoire, mettez à jour la liste Nom des utilisateurs et groupes autorisés à l'aide des boutons Ajouter et Supprimer.

    Supprimez tous les utilisateurs et groupes non autorisés. Assurez-vous notamment qu'aucun groupe ajouté à la liste ne contient le compte d'accès anonyme IUSR_machinename et que tous les comptes à accès large tels que TOUT LE MONDE sont supprimés.

  4. Dans la liste Nom, tapez le compte SYSTÈME de la machine.

    Ce compte est obligatoire pour permettre à IIS d'accéder au fichier pendant le processus de validation de sécurité.

  5. Pour chaque utilisateur ou groupe de la liste Nom, changez Type d'accès en Lecture.
  6. Cliquez sur Étendre aux dossiers inclus et Étendre aux fichiers existants, et cliquez sur OK pour accepter les modifications. Cliquez à nouveau sur OK pour fermer la boîte de dialogue Propriétés du dossier.

    7. Vous allez ensuite créer une racine virtuelle pour les formulaires d'administration HTML.

  7. Lancez l'application IIS Internet Service Manager.
  8. Double-cliquez sur le service WWW pour éditer ses propriétés.
  9. Dans l'onglet Répertoires, cliquez sur Ajouter.
  10. Dans le champ Répertoire, entrez l'emplacement du dossier Admisapi, en général
    C:\Program Files\Common Files\Microsoft Shared\Web Server Extensions\40\Admisapi.
  11. Dans le champ Alias, tapez /fpadmin
  12. Pour Accès, cliquez sur Lecture et sur Exécuter.
  13. Cliquez sur Exiger un canal sécurisé (SSL).
  14. Cliquez sur OK à deux reprises pour accepter les modifications.

 

Les formulaires sont maintenant activés pour une administration à distance lorsque vous explorez une URL telle que https://monposte/fpadmin/fpadmin.htm
