Rappel pour les utilisateurs occasionnels la consultation des stocks se fait sur : Site = SP-PINON - Magasin = MG-PINON-00
Dans les zones de couleur bleu ou grisé, vous pouvez faire apparaître une liste de choix en appuyant sur F4.
Dans toutes les listes, il est possible de créer un filtre (une requête) avec les raccourcis F2 Shift+F2

Saisie d'une commande de transfert inter-site :

  1. Saisir un numéro de commande non existant dans CDE, valider par Entrée
  2. Le programme vérifie l'existence ou non du numéro, si le numéro existe, la commande liée s'affiche.
  3. Saisir le reste de l'entête : Site demandeur, Responsable (matricule de la personne passant la commande), le site de départ, la langue utilisée pour le document, un commentaire visible sur le document.
  4. Sur la ligne article, saisir un code article ou faire une recherche par F4
  5. Indiquer le lieu de livraison (livré à), Site, Chantier, Magasin, le lieu d'origine Site, Chantier, Magasin
    Les CI, CR, NA se génèrent automatiquement.
  6. Se positionner sur une ligne à livrer, saisir une date de livraison, une quantité (Multiple de U. Qté), un commentaire
  7. Valider par F5, un numéro de demande est affecté.
  8. Reprendre à l'étape 4 pour saisir un nouvel article.
  9. En fin de saisie, cliquer sur pour éditer la commande.

Consultation / modification d'une commande :

  1. Saisir un numéro de commande ou faire une recherche par F4
  2. Valider par Entrée.
  3. En fin de modification, valider par F5, sinon quitter sans modifier avec F3
