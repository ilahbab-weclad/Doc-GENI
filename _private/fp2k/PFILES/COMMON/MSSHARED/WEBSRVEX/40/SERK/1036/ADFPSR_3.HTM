Kit de ressources des extensions serveur Microsoft FrontPage 2000

Fpsrvadm

Arguments de ligne de commande Fpsrvadm

Les arguments de ligne de commande Fpsrvadm sont regroupés ci-après.

 


Argument		 Forme
abrégée
Définition
Exemple
-port -p Numéro de port Entier, tel que 80, ou nom de serveur virtuel suivi d'un entier, comme sample.microsoft.com:80

Pour les serveurs Web IIS version 4.0 ou ultérieure, vous pouvez utiliser
-m NuméroInstance au lieu de
-m NomHôte -p nnnn
-web -w Nom de site Web FrontPage étendu URL d'un répertoire, par rapport à la racine de la zone de contenu, comme /monrépertoire
-type -t Type de serveur Web Sous UNIX :
apache, apache-fp (Apache avec correctif logiciel FrontPage), ncsa, netscape-enterprise, netscape-fasttrack, stronghold

Sous Windows :
frontpage, msiis (Microsoft Internet Information Services), mspws (Microsoft Personal Web Server), netscape-fasttrack, netscape-enterprise, website
-servconfig -s Fichier de configuration de serveur Web Chemin d'accès complet, comme /usr/local/apache/conf/httpd.conf
-multihost -m Nom de serveur virtuel ou adresse IP

Sur les serveurs Web IIS version 4.0 ou ultérieure, cet argument sert à indiquer un numéro d'instance.

 Adresse IP ou nom d'hôte WWW complet, comme dans 172.20.65.43, ou sample.microsoft.com.

Sous IIS version 4.0 ou ultérieure, numéro d'instance tel que /LM/W3SVC/10.

La chaîne vide "" signifie que le serveur n'est pas multi-hôte.
-username -u Nom d'utilisateur Sous IIS, cette valeur doit être un nom de compte utilisateur ou un nom de groupe Windows NT et peut être qualifié avec un nom de domaine, par exemple domain\username.

Sous UNIX et d'autres serveurs non-IIS, nom d'utilisateur nouveau ou existant dans la liste des accès du serveur Web. Il est recommandé de ne pas utiliser un nom d'utilisateur UNIX pour cette valeur car elle serait alors facile à deviner.
-password -pw Mot de passe Chaîne de mot de passe, comme 124Xyz. Cette valeur n'est pas nécessaire sur les serveurs IIS.
-ipaddress -i Adresse IP Adresse IP, telle que 172.22.12.12
-access -a Niveau d'accès accordé L'une des valeurs suivantes :

administrators, authors, users, remove.

La valeur remove supprime tous les accès du compte.
-destination -d URL d'un fichier ou dossier dans un site Web FrontPage étendu

Pour les commandes Putfile et Recalcfile, URL par rapport au répertoire de premier niveau du site, tel que
/monrépertoire/monfichier.htm.

Pour les commandes Setdirexec et Setdirnoexec, URL de dossier par rapport au répertoire de premier niveau du site, comme /monrépertoire/nouveaudossier.

Pour la commande Rename, URL par rapport au site racine, comme /nouveausous-site.
-filename -f Nom de fichier Chemin d'accès complet et nom de fichier, comme C:\Mesfichiers\Nomfichier.htm
-xUser -xu Nom de compte utilisateur UNIX (il doit s'agir d'un compte existant) Nom de compte utilisateur UNIX.
-xGroup -xg Nom de compte de groupe UNIX (il doit s'agir d'un compte existant) Nom de compte de groupe UNIX, tel que "www."
-noChownContent Yes -n yes Indique que seul le contenu des répertoires _vti* doit changer de propriétaire, non pas le contenu des utilisateurs. Aucun.
