1. DESCRIPTION DU PRODUIT
-------------------------
Microsoft ActiveX Data Objects (Multidimensionnel) (ADO MD) facilite l'accès aux données multidimensionnelles écrites dans les langages Microsoft Visual Basic, Microsoft Visual C++ ou Microsoft Visual J++. ADO MD est un complément de Microsoft ActiveX Data Objects (ADO) incluant des objets spécifiques aux données multidimensionnelles tels que les objets CubeDef et Cellset. Avec ADO MD, vous pouvez aisément parcourir des schémas multidimensionnels, effectuer une requête sur un cube et récupérer les résultats.
